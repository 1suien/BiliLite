# BiliLite 0.4.7（本机构建）—— 笔记行按钮调整 + 小窗播放改圆形气泡

这是 BiliLite 安卓前端源码还原工程的本机构建版：基于官方 0.4.4 的源码还原工程，加上三项本仓库自己的定制改动后重新构建出的**可直接安装的 APK**。

## 这一版改了什么

**1. 笔记行：去掉「▶ 跳转」，删除移到最右**

播放页「笔记」tab 里每条笔记右侧原来有「▶ 跳转」和「🗑 删除」两个按钮（跳转会 `player.seek()` 到记录的时间点）。按用户要求**完全去掉跳转**，时间点文字也不再可点；删除按钮挪到这一行最右侧。细节见 [docs/14](../docs/14-小窗圆形气泡与笔记行按钮.md)。

**2. 「小窗播放」改成右下角小圆圈**

- 播放页信息区的「小窗播放」文字按钮 → **圆形图标入口**；
- 播放中的视频不再是长方形小窗，而是右下角 **112×112 圆形气泡**：圆里是实时画面（裁成圆）+ 沿圆边的进度环 + 时间；
- **点一下气泡 = 回到播放页，从当前进度继续看**；气泡可拖动、跨页面常驻，右上角 × 关闭；
- 为了保持小圆圈形态，气泡里没有暂停/静音/拖进度（回播放页操作）。

- **0.4.6**：修正安卓设置页「备份目录 → 打开」实际弹「保存到…」的错位交互（安卓上隐藏该行、改为「备份位置」说明）；新增「恢复学习数据 → 打开 JSON 备份…」，与现有数据**合并**恢复 —— [docs/13](../docs/13-备份打开与导入恢复.md)
- **0.4.4**：同步上游 0.4.4 的剧场模式「退出剧场」竖白条修复 —— [docs/11](../docs/11-0.4.4同步记录.md)

## 校验

- `aapt2 dump badging`：package `com.bililite.app`，versionCode `11`，versionName `0.4.7`，minSdk 22，targetSdk 34
- `apksigner verify`：v1 + v2 通过（`CN=Android Debug`），`zipalign -c -p 4` 通过
- APK 内 `assets/public` 与构建目录 `app/dist` 逐字节一致（只多 `cordova.js` / `cordova_plugins.js`）
- `clean` 后重建的 APK 与增量构建 sha256 **完全相同**（可复现）
- 原生侧（4 个 dex、`AndroidManifest.xml`、`resources.arsc`）与官方 0.4.4 APK 逐字节相同，只有 web 层与版本号不同

## 已知限制

- 无头浏览器解码不了 mock 视频，**圆形气泡里的真实播放画面**未在真机确认（圆形裁切在竖屏/超宽视频上的观感需要实机看）；
- 圆形气泡内不提供暂停/静音/拖进度；
- 本仓库不包含原始 APK 与反编译产物（见 README「仓库说明」）；
- 构建环境为 aarch64 无 root，aapt2 经 qemu-x86_64 运行，详见 [docs/09](../docs/09-生成可安装APK.md)。
