# 笔记条支持多行（本机 0.4.60）

## 改动

- 笔记条输入从单行 `input` 换成 `textarea`：**Enter 换行**（不再回车保存）；
- 输入框随内容自动长高（单行起步，最高约 5 行 96px）；
- 保存方式：点「保存」或 `Ctrl/Cmd+Enter`；`Esc` 清空并失焦；
- 保存后输入框清空并缩回单行，下方小字刷新「最近：时间 · 内容」。

## 文件

- `app/src/views/VideoView.vue`：`.nb-field` 改 `textarea` + `autoGrowNote()`；`noteInputEl` 类型改 `HTMLTextAreaElement`；
- `app/src/styles/global.css`：`.nb-field` 加 `resize:none; overflow:hidden; line-height:1.5`。
