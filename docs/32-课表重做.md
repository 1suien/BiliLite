# 32 课表重做：周卡片 → 时间块（本机 0.4.29）

> 为什么改：旧课表是「课程 × 星期」的周卡片，点开只能看到「几点 · 上什么」，回答不了每天最该回答的三个问题——**现在做什么、还剩多久、接下来是什么**。用户原话（2026-10-30）：「优化一下课表功能，不需要其他功能，能看要干什么」。
>
> 方案与四张界面稿见 [31-课表优化方案.md](31-课表优化方案.md) 与 `docs/mockups/`；本篇记录落地实现。

## 1. 模型：一条记录 = 一个时间块

```ts
// app/src/types.ts
export type SlotKind = 'study' | 'break'
export interface ScheduleSlot {
  id?: number
  name: string        // 做什么：新三 / 跟读 / 冥想 …
  kind: SlotKind      // 学习 | 休息（休息不计入学习时长）
  start: string       // 'HH:MM'
  end: string         // 'HH:MM'
  days: number[]      // 出现在哪些星期：1 周一 … 7 周日（可多选）
  color?: string      // 仅休息块用得上，默认灰
  targetName?: string // 关联专注目标（可选）
  bvid?: string       // 关联 B 站视频（可选）
  videoTitle?: string
  remindOn: boolean   // 开始前提醒
  remindLead: number  // 提前几分钟（默认 5）
  note?: string
  createdAt: number
}
```

- **取消「课程」概念**：不再有「课程名」和「提醒时间」两套时间，一个块只有起止时间。
- **一条记录可以出现在多天**（`days: [1,2,3,4,5]` 就是工作日每天都有），改一次全周一起变。
- **完成状态按天存**（`localStorage: study-bili-slot-status`），结构 `{ '2026-10-30': { '12': 'done' } }`；没标记过就按时间推断：已经过去 = 已完成，正在其中 = 进行中，还没到 = 待开始。显式 `todo` 用来撤销「过去时段」的完成标记（否则按时间推断又会变回已完成）。

## 2. 数据层

| 文件 | 改动 |
| --- | --- |
| `app/src/types.ts` | 新增 `SlotKind` / `ScheduleSlot` / `SlotStatus` |
| `app/src/stores/slots.ts` | 新文件：`parsePlanText()`（表格四列 → 时间块）、`useSlotsStore`（增删改查、按天状态、统计） |
| `app/src/db/index.ts` | `slots` 表，Dexie `version(10)`；`version(9)` 之后追加，保证老库按顺序升级 |
| `app/src/stores/courses.ts` | **删除**（0.4.12 的旧课表数据，自动迁移后不再引用） |

老库迁移（`migrateCoursesToSlots`，只跑一次，标记 `study-bili-slots-migrated`）：旧的 `Course`（只有 `weekday` + `remindAt` + 45 分钟固定）→ `ScheduleSlot`：`start = remindAt`、`end = remindAt + 45 分钟`、`days = [weekday]`、`kind = 'study'`、`remindLead = 5`。

## 3. 页面（`app/src/views/ScheduleView.vue`）

- **今日**：第一屏就是答案——现在卡片（做什么/起止/剩余分钟/进度环/开始专注·标记完成·跳过）→ 下一项 → 按「早晨/上午/下午/晚上」分组的时间轴 → 右栏（今日进度、接下来、提醒说明、清空今天）。
- **全周**：7 列时间块，今天那列高亮，进行中的块用品牌色；有内容的块显示起止时刻。
- **编辑抽屉**：做什么 / 学习·休息 / 开始·结束时间（自动算时长）/ 星期多选 / 关联（专注目标、B 站视频）/ 提醒开关 + 提前分钟 / 备注 / 删除。
- **从表格粘贴**：粘贴 WPS/Excel 复制的四列（开始·结束·做什么·类型；没有类型列时按关键词判断，冥想/休息/运动 = 休息），右侧实时预览识别结果，选星期后一次生成；自动跳过表头、合并单元格和「上午/下午」分隔行。

## 4. 提醒

`app/src/stores/remind.ts` 从「课程」切到「时段」：

- `dueSlots()`：每个块按 `remindLead` 算提醒时间，窗口 `[提醒时间, +10 分钟)`，key `slot:<id>:<day>`。
- 到点：`ReminderCards` 弹「课表提醒」卡片（新增 `slot` 类型），可选「专注 25 分钟」/「知道了」；上课时刻还会发系统通知（`nativeItems()` 里生成未来 8 天，交给已有的提醒/通知通道）。
- `App.vue` 改为 `useSlotsStore()` 的初始化与 `watch(slots.list)`。

## 7. 已知限制

- 不支持跨天时段（如 23:30–00:30）——粘贴与编辑时都会校验结束晚于开始。
- 表格粘贴只认 `HH:MM` 四列格式，其他格式不猜。
- 全周视图的时间块按起点排序，同一时刻的叠加块会并列显示（不会自动错开）。
