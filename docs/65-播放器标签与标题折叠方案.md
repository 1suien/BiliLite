# 播放器右上角清清晰度标签删除 + 标题区折叠（方案，未写代码）

## 需求

1. 删除播放器**右上角**的清晰度标签（截图红圈 `1080P ▾`）；
2. 视频下方那一整块（标题 / 正在播放 / UP·BV·时间 / 收藏等按钮）要能**折叠**：点一下展开，再点一下收起。

## 方案

### 1）删掉右上角清晰度标签

- 删 `app/src/views/VideoView.vue` 里 `.q-badge` 元素（以及它的点击处理）；
- 清晰度**只保留控制条里的「1080P」按钮 + 弹出菜单**（0.4.45 已经做了），菜单里当前档位打勾；
- 顺带把点击舞台时 `closest('.q-badge')` 的排除逻辑去掉，避免残留；
- 结果：视频右上角干净，档位切换仍可用。

### 2）标题区折叠：现在的问题与改法

**现在**：默认折叠成一行（`▸ 标题 … 展开 ⌄`），点开展开后**没有「收起」入口**——想收回去只能靠刷新/重进页面。这就是「点击打开再点击折叠」不方便的原因。

**改法**：
- 折叠条保留：`▸ 标题 … 展开 ⌄`，点击展开；
- **展开态加明显的收起按钮**：在标题行右端显示 `收起 ⌃`（和操作按钮同一行右侧），点它收起；
- **点标题也能收起**（整行标题点击切换，触屏更好按）；
- 折叠状态继续记 localStorage，默认折叠；
- 折叠/展开不重新拉流、不影响播放。

### 3）可选（默认不做）

- 折叠条上显示当前播放进度（`P29 · 12:34`），信息多一点；
- 展开时自动滚到标题位置。

## 改动文件

| 文件 | 改动 |
| --- | --- |
| `app/src/views/VideoView.vue` | 删 `.q-badge`；展开态加「收起 ⌃」；标题点击收起 |
| `app/src/styles/global.css` | 收起按钮样式；`.q-badge` 样式删除 |

## 验收

- 播放页右上角无档位标签；控制条点「1080P」能弹菜单换档；
- 折叠条点开 → 完整信息出现、右端有「收起 ⌃」→ 点它或点标题 → 收成一行；
- 刷新后保持上次状态；播放不中断。
