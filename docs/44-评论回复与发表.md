# 评论回复与发表（本机 0.4.38）

## 做了什么

在 0.4.36/0.4.37 的「评论区（只读）」基础上加了**发表能力**：

- 评论 tab 顶部一个输入框：写内容 →「发表」，发表后切到「最新」并刷新列表；
- 每条主评论、每条楼中楼回复后面都有「回复」：点了会在顶部出现「回复 @某人」提示条，发送时自动带 `回复 @某人 :` 前缀，可点「取消」撤销；
- 字数上限 1000，实时显示 `已写/1000`；`Ctrl+Enter`（Mac 为 `Cmd+Enter`）快捷发表；
- 未登录时输入框提示「登录后才能发表评论」，点发表会提示去右上角「扫码登录」；
- 发表失败（风控、审核、网络）原样弹出接口返回的提示，方便判断原因。

## 接口

`POST https://api.bilibili.com/x/v2/reply/add`（`application/x-www-form-urlencoded`）

| 参数 | 说明 |
| --- | --- |
| `oid` | 视频 aid |
| `type` | 固定 `1`（视频） |
| `message` | 评论正文（回复时是 `回复 @xxx :内容`） |
| `root` | 回复时传：主评论的 rpid（顶层评论不传） |
| `parent` | 回复时传：被回复那条的 rpid（顶层评论不传） |
| `plat` | `2`（网页端） |
| `csrf` | cookie 里的 `bili_jct` |

实测：**不带登录态返回 `-101 账号未登录`**（说明接口不强制 WBI 签名，csrf 校验即可）。

## 已知限制

- 只支持**纯文字**：图片、表情包、@ 搜索、表情面板都没做（表情可以先手打 `[保佑]` 这类文字码，服务端会渲染成表情）；
- B 站有评论审核与频率限制：发太快或触发风控会返回错误（如 `-412` 需要验证码），页面会显示接口返回的 message；
- 发表后是「切到最新 + 重新拉第一页」，没有做本地乐观插入（避免排序错乱）。
