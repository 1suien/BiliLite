# 播放页改版：删顶栏 + 视频满宽 + 常驻清晰度/分P 工具栏 + 标题折叠（本机 0.4.55）

基于 0.4.44 结构（0.4.54 基线），按 0.4.55 方案改：

## 改了什么

1. **删掉整块顶栏**（`app/src/App.vue` 的 `<header class="top">`），「剧场模式 / 返回」两个按钮没有了；剧场模式仍可用 `F` 进入；
2. **视频满宽**：去掉播放页右侧「清晰度 / 分P」两栏，`.watch` 改单列（1220 视口下视频 758 → 972，+28%）；
3. **视频下方常驻工具栏**：左边「清晰度」档位 chips，右边「分P 共 N P · 当前 … ▾」下拉（弹 `PartList`）；工具栏在播放器外，**播放时不会隐藏**，随时能切；
4. **标题区折叠**：默认一行 `▸ 标题 …… 展开 ⌄`，点行任意位置展开；展开后是标题 + 收起 ⌃ + 正在播放 + UP/BV/时间 + 收藏/关注/加入学习清单/学习面板/小窗；状态记 `study-bili-video-head-collapsed`；
5. tabs 不变：简介 / 笔记 / 相关推荐 / 评论。

## 改动文件

- `app/src/App.vue`：删顶栏
- `app/src/views/VideoView.vue`：删右侧 aside；新增 `.media-toolbar`（清晰度 chips + 分P 下拉）、标题折叠两态、`partsOpen/pickPart`、`headCollapsed/toggleHead`
- `app/src/styles/global.css`：`.watch` 单列、`.media-toolbar`、`.parts-pop`、`.head-collapsed`、`.head-open`

## 验证

- 浏览器 mock：无 `header.top`、`.media-toolbar` 存在、播放器宽 972、折叠行存在且点击可展开、分P 弹层可开；
- `npx vue-tsc --noEmit` 通过、`npm run build` 通过、`cap sync` + `gradlew assembleDebug` 通过。
