# 播放页第二版：清晰度进视频、分P 挪到简介右边（方案，未写代码）

## 现状

- 播放页是「左视频 + 右窄栏」，右栏从上到下：清晰度卡片、分P列表卡片；
- 清晰度是卡片里一排按钮，占掉右栏最上面一块；
- 分P列表（155 个分P、分组、筛选框）占满右栏剩下高度，得滚动找。

## 目标

1. **清晰度移到视频里面** —— 播放器控制条上直接切清晰度，右栏不再有清晰度卡片；
2. **分P列表放到「简介」右边** —— 变成 tab 的一页，标题行加数量。

## 方案

### 1. 清晰度：进控制条

- 控制条右侧（1x 倍速 / CC / 音量 旁边）加一个 `1080P` 小按钮；
- 点它，**向上弹**出清晰度菜单：`1080P+`、`1080P`、`720P`、`480P`、`360P`；
  - 当前档位打勾；未登录/大会员档位置灰 + 小锁（沿用现在的 `isLocked()` 判断）；
- 选中即切换（沿用现有 `selectQuality()`，会落盘到设置里的默认清晰度）；
- 视频右上角同时显示当前档位（半透明小标签，点击也能开菜单）；
- 右栏的「清晰度卡片」删除。

### 2. 分P 列表：变成「简介」右边的 tab

tabs 变成：

```
简介   分P(155)   笔记(0)   相关推荐   评论(4620)
```

- 「分P(n)」tab 内 = 现在右栏那套列表：分组标题（开篇/L006/L007…）、筛选框（编号或标题关键字）、点击切换分P、当前分P高亮、「跳到当前」按钮；
- 默认 tab 仍是「简介」；如果上次看到一半，进入时自动滚到「跳到当前」附近（可选，P1）；
- 切分P不刷新整页（和现在一样），tab 内容滚动。

### 3. 布局影响

- 右栏清空 → 播放页变**单栏**：视频按 16:9 拉宽（宽屏最大 ~1200px 居中），下面标题/简介/收藏/学习面板一排；
- 顶部「剧场模式」按钮保留；
- 窄屏（<900px）自然单列，不需要额外适配。
