# 分P 弹层修复 + 播放页留出笔记空间（方案，未写代码）

## 1）分P 弹层「有问题」的原因

截图里分P 列表：分组标题压在白条上、分P 行文字被盖住/挤在一起。原因有三：

1. `PartList` 是为**右栏宽卡片**写的（`styles/recovered/PartList.css`）：
   - `.grp` 是 `position: sticky` 且 `background: var(--card)`（浅色主题下是白底）→ 在窄弹层里变成一条白条压住上面的分P 行；
   - `.pages-list` 有 `max-height: clamp(373px,56vh,560px)` 与 `scrollbar-gutter: stable`，和弹层自己的滚动条叠在一起；
2. 弹层宽度只有 `340px`，而分P 行是「P 号 + 标题」两列，标题被挤到换行/截断；
3. `.ctl-menu` 的内边距和 `.pages` 的内边距叠加，行高不够。

### 改法

- 弹层加宽到 `440px`，最大高度 `min(70vh, 560px)`，内部只有一层滚动；
- 在 `.parts-menu` 里覆盖 PartList 的样式（不动 PartList 本体，避免影响别的用法）：
  - `.grp { position: static; background: transparent; }`（去掉白条、去掉粘滞）；
  - `.pages-list { max-height: none; overflow: visible; padding-right: 0; }`；
  - `.page-pill { min-height: 32px }`，`.pn` 固定宽度、`.pt` 单行省略；
- 保留：筛选框、L001 分组、当前分P 高亮、「点了就切」。

## 2）视频播放留出笔记空间

目标：一边看一边记，不用切 tab、不用滚动找输入框。两个方案：

### 方案 A：右侧常驻笔记栏（推荐）

```
┌────────────── 视频（左，占 2/3） ──────────────┐ ┌─ 笔记（右，320px）─┐
│                                                  │ │ 输入框（带当前时间）│
│                                                  │ │ ──────────────── │
│                                                  │ │ 12:34 笔记1  ⤴跳转 │
│                                                  │ │ 08:12 笔记2  ⤴跳转 │
└──────────────────────────────────────────────────┘ └────────────────────┘
```

- 视频与笔记**并排**，笔记栏常驻、内部滚动，不占视频下方空间；
- 输入框自动带当前时间（`@ 12:34`），Ctrl+Enter 保存；
- 笔记列表里时间戳可点 → 视频跳到那一刻；
- 视频宽度变窄（16:9 会小一圈），窄屏（<1100px）自动改成上下：视频在上、笔记在下固定 200px 高。

### 方案 B：视频下方常驻笔记条

- 视频保持现在的宽度，下面固定一条「笔记」区（高约 160px，内部滚动 + 输入框）；
- tabs 里的「笔记」tab 去掉；
- 好处：视频不缩小；坏处：一屏内能看到的笔记行数少。
