# 分P 浮层修复 + 视频右侧常驻笔记栏（本机 0.4.50）

## 1）分P 浮层修复

问题（用户截图）：分组标题白条盖住分P 行、文字挤在一起。根因是 `PartList` 原本给右栏宽卡片设计：

- `.grp` 是 `position: sticky` + `background: var(--card)` → 在窄浮层里变成白条压在行上；
- `.pages-list` 自带 `max-height` + 滚动条，和浮层滚动叠加；
- 浮层 340px 太窄，「P 号 + 标题」两列挤爆。

修法：

- 分P 浮层改为播放器内的**独立浮层** `.parts-pop`（不再塞进控制条 `.ctl-menu`），宽 400px，`bottom: 62px`，自带标题栏与关闭按钮；
- 在 `.parts-pop` 内覆盖 PartList 样式：`.grp { position: static; background: transparent }`、`.pages-list { max-height: none; overflow: auto }`、行高 32px、标题单行省略；
- 控制条里只保留「分P N」按钮，点击开/关浮层。

## 2）视频右侧常驻笔记栏

- `.watch` 改为两列：`minmax(0,1fr) 320px`，左视频、右笔记栏；
- 笔记栏 `.note-side`：标题（笔记 / 条数 / 当前时间）、输入框（placeholder 带 `当前时间`，Ctrl+Enter 保存）、笔记列表（时间戳可点 → 视频跳到该处、✕ 删除）、空态提示；
- 窄屏（≤1100px）自动单列，笔记栏排到视频下方；
- 删掉原 tabs 里的「笔记（N）」tab 与其面板，tabs 现在只有：简介 / 相关推荐 / 评论；
- 新增 `jumpNote(sec)`：`player.requestSeek(sec)`，跳转沿用播放器防抖逻辑。
