# 开屏（Splash）方案：It's never too late to learn（本机 0.4.65）

## 现状

- 启动时显示的是 **Capacitor 默认开屏图**：白底 + 蓝色默认图标（`app/android/app/src/main/res/drawable*/splash.png`，6 组密度都是默认图），和 App 的黑白极简风格不一致，还会“白闪一下”；
- 没有开屏文案，启动完成直接进首页。

## 目标

冷启动时：深色底 → 「学」logo → **It's never too late to learn**（衬线斜体）→ 小字「学习，永远不晚」→ 底部细进度条 → 淡出进 App。全程无白闪。

## 推荐方案 A：原生图 + Web 开屏层（混合）

1. **原生启动图替换**：把 6 组 `drawable-port-*/land-*/splash.png` 全部换成深色 `#0a0a0b` 底 + 白色 logo + 句子（文字烧进 PNG，冷启动第一帧就是黑底，不会闪白）；
2. **Web 开屏层**：`index.html` 里内联一段 splash（同设计，矢量大字 + 进度条动画），`main.ts` 的 `boot()` 完成后淡出并移除（最少展示 800ms、淡出 240ms）；
3. **时序**：原生图 → Web splash（视觉连续）→ 淡出到首页；只冷启动一次，路由切换不再出现；
4. **异常兜底**：启动超过 3 秒，底部加小字「正在加载数据…」；启动失败也保证能进 App（超时 8 秒强制淡出）；
5. **可访问性**：`prefers-reduced-motion` 时去掉动画、直接显示。

设计参数（见效果图 `docs/mockups/26-splash.png`）：

- 底：`#0a0a0b`；logo：白色 96×96 圆角 26px 的「学」；
- 主句：Georgia / Times 斜体 46px，白色，最大宽 860，居中；
- 副标题：「学习，永远不晚」，15px，`#8b8b95`，字距 2px；
- 底部进度条：132×3，深灰轨道 + 白色滑块循环。

## 备选

- **方案 B：只换原生 PNG**：最简单（改 6 张图），但没动画、不能显示加载状态、小字在大屏上可能发糊。
- **方案 C：只做 Web 层**：不动原生图 → 会先闪一下默认白图，不推荐。

## 改动文件

- `app/android/app/src/main/res/drawable-port-*/splash.png`、`drawable-land-*/splash.png`（重新生成）；
- `app/index.html`（内联 splash 结构）、`app/src/main.ts`（boot 后移除 + 超时兜底）、`app/src/styles/global.css`（splash 样式/动画）；
- 可选：`app/src/stores/settings.ts` 加「显示开屏」开关（P1）；
- `docs/86`（本文）。

## 验收

- 冷启动第一帧是深色（无白闪），句子和 logo 居中不裁切；
- 横屏/竖屏、平板 2880×1800、手机窄屏都正常；
- 首页出现后 splash 淡出干净，不影响后续路由；
- 启动 3 秒以上出现「正在加载数据…」，最长 8 秒必消失。

## 三个默认（不回就按这个）

1. 走方案 A（原生图 + Web 开屏层）；
2. 固定深色底 + 白色 logo（不随主题变化）；
3. 最短 800ms、淡出 240ms、只冷启动显示一次。

---

## 实现（0.4.65）

- **原生开屏图**：重新生成 11 张 `res/drawable*/splash.png`（深色 `#0a0a0b` 底 + 白色「学」logo + 句子 + 副标题 + 进度条），尺寸与原来各密度一一对应；
- **Android 12+ 系统开屏**：`values/styles.xml` 的 `AppTheme.NoActionBarLaunch` 增加 `windowSplashScreenBackground=@color/splashBackground`、`postSplashScreenTheme=@style/AppTheme.NoActionBar`；`colors.xml` 新增 `splashBackground=#0a0a0b`，系统开屏底色也是黑的；
- **Web 开屏层**：`app/index.html` 内联 `#boot-splash`（含淡入动画、进度条、`prefers-reduced-motion` 处理），先于 JS 显示；
- **收起逻辑**：`app/src/main.ts` 的 `hideBootSplash()`——最少展示 800ms、淡出 280ms 后移除；`boot()` 成功或失败都会收起；3 秒显示「正在加载数据…」；8 秒兜底强制收起；
- 校验：`vite preview` + Playwright 确认加载瞬间 `#boot-splash` 存在、1.6 秒后已移除，页面正常（截图 /tmp/v65-splash.png）；
- 构建：`vue-tsc` + build + cap sync + gradle 56s；APK `BiliLite-0.4.65-debug.apk` 4,207,933 B / sha256 `caea49b06d15297accf8a7aae04475b799f759d1f9764822930f625d6ba0e514` / versionCode 69；`/dl` 200。
