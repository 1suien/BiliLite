## 演示模式（`?mock=1`）——本工程新增，不属于原 APK

原 APK 的渲染层只认原生注入的 `window.bili`，用浏览器直接打开只会看到「未检测到桌面端桥接」。为了能在电脑上验收，加了三个东西：

1. **`app/src/bridge/mock.ts`**（645 行）：内存假数据桥，实现 `WbiBridge` 的**全部方法**（视频/搜索/UP/收藏/登录/设置/本地文件/备份）。图片用 `cover(text, hue)` 现场生成 SVG data URL（不依赖外网）；播放地址是 `mock://video/1080p`（会被 CSP 拦，属预期）。
2. **`app/src/dev/seed.ts`**（189 行）：进 mock 模式时往 IndexedDB 种一批演示数据，否则学习/习惯/本地页全空。只在 `db.progress.count() === 0` 时种，避免覆盖你自己的数据。
3. **`main.ts` 的桥选择分支**：
   ```ts
   const mockMode = new URLSearchParams(location.search).has('mock')
     || !!(import.meta.env?.DEV && !window.bili)
   ```

种了什么（数字经过设计，让每个页面都有内容）：

- 6 条学习进度（`BV1mock0001…0006`，含 极客湾/罗翔/何同学/半佛/影视飓风 等真实 UP 名）；
- 最近 30 天每日时长（最后三天固定 2460/3300/1800 秒，保证「今日/本周」有数）；
- 12 天签到、4 条 UP 时长、3 条学习清单；
- 2 个 UP 分组 + 4 个 UP、本地收藏夹（默认收藏夹 + 学习资料）；
- 4 个习惯（1 个已归档）+ 14 天打卡记录；
- 12 条专注记录、3 个本地视频（`/mock/课程视频/*.mp4`）。

**清空演示数据**：浏览器 DevTools → Application → IndexedDB → 删除 `study-bili`，或
```js
indexedDB.deleteDatabase('study-bili'); location.reload()
```

### 无头 Chromium 的环境本地化（本机特有）

本机没有 root，Chromium 缺 `libglib-2.0.so.0` 等系统库，也没有中文字体，直接 `chromium.launch()` 会：

- 先报 `libglib-2.0.so.0: cannot open shared object file`；
- 补完库后报 `FATAL:third_party/skia/src/ports/SkFontMgr_FontConfigInterface.cpp:163 Not implemented`（FontConfig 找不到字体配置）。

解决办法（**已固化进仓库**，无需重做）：

1. `tools/browser/chromium-libs/root/usr/lib/aarch64-linux-gnu/`：把需要的 Debian 包用 `apt-get download` 下下来、`dpkg-deb -x` 解包到这里（约 138 MB，勿删）；
2. `tools/browser/chromium-libs/fonts-root/usr/share/fonts/`：`fonts-noto-cjk` + `fonts-dejavu-core` 解包；
3. `tools/browser/fonts.conf`：指向上面的字体目录；
4. 运行脚本时注入：
   ```bash
   LD_LIBRARY_PATH=tools/browser/chromium-libs/root/usr/lib/aarch64-linux-gnu:/usr/lib/aarch64-linux-gnu \
   FONTCONFIG_FILE=tools/browser/fonts.conf \
   FONTCONFIG_PATH=tools/browser \
   HOME=/tmp/pw-home node tools/browser/shot.mjs
   ```
   `shot.mjs` 里的 `browserEnv()` 会自动设这些变量，所以上面可以省略。

> 换一台有 sudo 的机器：`npx playwright install --with-deps chromium` 即可，不需要 `chromium-libs/`。

## 常见问题

| 现象 | 原因 / 解决 |
|---|---|
| 页面显示「未检测到桌面端桥接」 | 用了 `preview`/`build` 但没加 `?mock=1`；或 dev 模式下 `window.bili` 被其他脚本占用 |
| 页面是空的（数据全 0） | IndexedDB 里已有旧数据（seed 只在空库时种）；删 `study-bili` 库后刷新 |
| 播放页红框「这条线路暂时拿不到数据」 | mock 的 `mock://` 被 CSP 拦，预期行为；真机/真接口不会 |
| 中文显示成方块 | 无头浏览器没读到字体，检查 `FONTCONFIG_FILE`；真实浏览器不受影响 |
| `chromium.launch` 报缺 `libglib` / `FontConfigInterface` | 见上文「环境本地化」，或换有 sudo 的机器 |
| 截图被挤压/布局错乱 | 必须用平板/桌面宽度（≥ 1000px），这个 App 没有响应式断点 |
| 真机上接口 403 / 需要登录 | 桥里会自动重签 WBI 并提示扫码；确认 `capacitor.config.json` 的 `hostname: www.bilibili.com` 没改 |
