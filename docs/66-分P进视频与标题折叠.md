# 分P进视频 + 右上角标签删除 + 标题折叠开关（本机 0.4.49）

## 1）分P 进视频

- 控制条新增「分P N」按钮（位于清晰度右侧），点开在播放器内弹出分P列表：
  - 复用 `PartList` 组件（`compact` 模式，隐藏自带标题栏）；
  - 保留筛选框（>12 个分P 时出现）、`L001` 分组、当前分P 高亮、点了就切；
  - 切完自动收起弹层。
- 下面 tabs 里的「分P（N）」tab 与其面板已删除，tabs 变成：简介 / 笔记 / 相关推荐 / 评论。

## 2）删除播放器右上角清晰度标签

- 删除 `.q-badge` 元素及其点击处理；清晰度只保留控制条「1080P」按钮 + 弹出菜单（当前档打勾）。

## 3）标题区折叠可来回切

- 折叠态：一行 `▸ 标题 … 展开 ⌄`，点击展开；
- 展开态：标题行右端新增「收起 ⌃」，点它或直接点标题即可收起；
- 状态记 localStorage，默认折叠，不重拉流。
