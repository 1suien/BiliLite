# 学习页布局改版（本机 0.4.43，方案 C2）

## 为什么改

删掉「今日习惯」卡后，学习页只剩专注面板自己的两列：左列（专注目标 + 计时条）约 200px 高，右列（概览 4 个数字 + 专注记录）500px 多，**左列下方空了半屏**，页面重心全偏右；下面再跟两个 tab，整页看着散。

## 改成什么样（方案 C2）

```
┌ 今日番茄 2轮 │ 今日专注 1h15m │ 总番茄 12轮 │ 总专注时长 6h40m ┐   第一行（新增）
├─────────────────────────────────────────────────────────────────┤
│ 专注目标                                                          │
│  左：目标列表（坚持中/已归档、每个目标开始/暂停/设置提醒）         │   整宽专注卡
│  右：大圆环倒计时 + 已过进度 + 「开始专注 / 重置」+ 时长设置/全屏  │
├─────────────────────────────────┬───────────────────────────────┤
│ 学习进度(4) / 学习清单(0) 列表   │ 专注记录（限高 560px，内部滚动）│   下排
└─────────────────────────────────┴───────────────────────────────┘
```

- 第一行概览：4 个数字横排等宽，独立卡片；
- 专注卡：整宽，左边目标列表、右边大圆环（用 `conic-gradient` 画，`--p` 是已过百分比），下面一行按钮；
- 下排：左 2/3 是原来的「学习进度 / 学习清单」tab + 列表，右 1/3 是专注记录（卡片内滚动，不再把页面撑长）；
- 窄屏（<900px）自动退化成单列：概览 → 专注卡 → 学习进度/清单 → 专注记录。

## 改动文件

| 文件 | 改动 |

| `app/src/components/FocusOverview.vue` | 新增 `compact` 属性：`compact` 时隐藏标题栏、4 列横排（原来 2×2 带「概览 / 全部历史」标题） |

数据、接口、其他页面都没动。
