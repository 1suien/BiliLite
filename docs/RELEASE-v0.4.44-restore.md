## BiliLite 本机构建 0.4.44（debug 签名，可直接覆盖安装，数据保留）

修「视频一直卡在缓冲中、30 秒不动」：部分 B 站 CDN 线路会「返回响应头 + 发完 init 段后不再发数据」，旧代码只有首包超时、首字节一到就不管了，于是读流永远挂着。

- 拉流空闲看门狗：连上后 6 秒没有新字节 → 自动断开、换备用线路，并在状态栏提示；
- 所有线路都不行 → 自动重新取一次播放地址；仍失败则错误卡片给「换 720P 试试」；
- 调试行新增「换线 N 次」和当前线路 host，方便定位是哪条 CDN 的问题。

- 源码：分支 `restore/android-0.4.3`，tag `v0.4.44-restore`
- 说明：[docs/56-拉流看门狗.md](https://github.com/1suien/BiliLite/blob/restore/android-0.4.3/docs/56-拉流看门狗.md)
