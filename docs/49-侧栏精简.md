# 侧栏精简：隐藏入口、保留功能（本机 0.4.41）

## 做了什么

- 侧栏只保留 **学习 / 习惯 / 课表**；
- 「本地」从主区移除；
- 「更多」分组（UP 管理 / 收藏 / 设置）整块移除（模板里的 `side-more` 块已删除，不留空白）；
- 功能全部保留：4 个页面、路由、数据不动，入口统一走**点头像的快捷菜单**（本地 / UP 管理 / 收藏 / 设置 / 退出登录）；
- 侧栏拖拽排序仍可用（只剩 3 项），`settings.navOrder` 里隐藏项的历史顺序不清空；
- 深链可用：`#/local`、`#/fav`、`#/ups`、`#/settings` 直接打开仍正常。

## 实现

| 文件 | 改动 |
| --- | --- |
| `app/src/App.vue` | 新增 `SIDEBAR_HIDDEN = ['/local', '/ups', '/fav', '/settings']`；`mainNav` 过滤隐藏项、`moreNav` 恒为空数组；删除侧栏「更多」`<nav>` 块；头像菜单改为固定顺序（本地 / UP 管理 / 收藏 / 设置），标签图标仍取 `NAV_ITEMS` |
| 无 | 路由、stores、页面组件、设置项均未改 |
