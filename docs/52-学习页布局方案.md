# 学习页布局优化（计划，暂未写代码）

## 为什么现在看着不舒服

删掉「今日习惯」卡后，学习页只剩 `FocusPanel`，它内部是两列：

```
左列：专注面板（目标 chip + 开始/切换 + 计时条）    ← 很短
右列：今日概览（4 个数字卡） + 专注记录（长列表）    ← 很长
```

结果**左列到右列中间空了半屏**，上下也不对齐；下面再跟「学习进度 / 学习清单」两个 tab，整页重心偏右，看着就散。

## 方案 A（推荐，改动最小）

把两列重新分配成「左短右长」的平衡结构：

```
┌───────────────────────────────┬──────────────────────────────┐
│ 专注面板（目标 + 计时）        │  专注记录                     │
│ ─────────────────             │  （限高 ~420px，内部滚动）      │
│ 今日概览（2×2 数字卡）         │  ─────────────────────────    │
│                               │  空状态时显示提示              │
└───────────────────────────────┴──────────────────────────────┘
┌ 学习进度（4） / 学习清单（0） ────────────────────────────────┐
│ 记录列表 / 清单列表（保持现状）                                │
└──────────────────────────────────────────────────────────────┘
```

具体：

1. `FocusPanel.vue` 内部把 `FocusOverview` 从右列移到左列（放到专注面板下面），右列只留 `FocusRecords`；
2. `.focus-layout` 两列都 `align-items: stretch`；右列记录卡 `max-height: 420px`，卡片内部滚动（`overflow: auto`），左右高度接近；
3. 左列两张卡之间 12px 间距；两列总高度控制在一屏内（约 520px）；
4. 页面顶部留白从 20px 收紧到 12px，让第一张卡离顶栏近一点；
5. 无记录时右列显示空状态（「打开视频自动记录」），不再是一整列空白；
6. 窄屏（<900px）仍退化成单列：专注 → 概览 → 记录。

## 方案 B（备选）

保持两列，但把右列 `FocusRecords` 限高 + 左列补一张卡（如「继续上次学习」）。比 A 多做一个组件，效果未必更好。

## 方案 C（备选）

整个学习页改单列：专注 → 概览（横向一排 4 个数字）→ 记录（限高）→ 进度/清单。信息密度低一些，但最不容易乱。

## 改动清单（按方案 A）

| 文件 | 改动 |
| --- | --- |
| `app/src/components/FocusPanel.vue` | 模板把 `<FocusOverview />` 移到左列 `.ft` 之后；`.focus-layout` 加 `align-items: stretch`；`.focus-right .records` 限高 + 内部滚动；左列卡片间距 12px |
| `app/src/components/FocusRecords.vue` | 记录列表外层加可滚动容器（`max-height: 420px`），表头固定 |
| `app/src/styles/global.css` | 学习页顶部 padding 20 → 12（`.view`/`.content` 里对应类） |
| 无 | 数据结构、接口、其他页面不动 |

## 验收

1. 两列高度接近，左列不再出现半屏空白；
2. 专注记录超过 6 条时在右侧卡片内滚动，不把页面撑长；
3. 无记录时显示空状态，布局不塌；
4. 900px 以下单列顺序：专注 → 概览 → 记录；
5. 下方「学习进度 / 学习清单」tab 与列表位置不变，切页正常。
