# BiliLite 0.4.8（本机构建）—— 离开播放页时视频自动缩成暂停小圆

这是 BiliLite 安卓前端源码还原工程的本机构建版：基于官方 0.4.4 的源码还原工程，加上本仓库自己的几项定制改动后重新构建出的**可直接安装的 APK**。

## 这一版改了什么

**播放中离开播放页 → 视频自动缩成右下角小圆并暂停**

- 播放视频时点左侧导航（或首页卡片、返回等**任何**离开播放页的入口），视频不再直接消失，而是**自动缩成右下角 112×112 圆形小窗并暂停**，画面停在离开的那一帧；
- **点小圆 = 回到播放页，从暂停处自动继续播**；
- 同页换分P、换视频、刷新/关窗口、拉流失败都不触发；已经在小窗里再离开不重复；
- 手动圆形「小窗播放」入口行为不变（进小窗并继续播）。

细节与实现见 [docs/15](../docs/15-离开播放页自动暂停小窗.md)。

## 已知限制

- 真机上的**暂停帧**没实测：浏览器里是 canvas 录制的 webm，真机 DASH 流暂停时个别清晰度可能要先等画面出来；
- 离开时若还在「缓冲中…」（拉流未就绪），也会缩成小圆，小圆里会继续尝试拉流并显示缓冲状态；
- 暂停态的小圆仍会拉流（用于定格画面），想省流量可后续改成「点回播放页再加载」；
- 本仓库不包含原始 APK 与反编译产物（见 README「仓库说明」）；
- 构建环境为 aarch64 无 root，aapt2 经 qemu-x86_64 运行，详见 [docs/09](../docs/09-生成可安装APK.md)。
