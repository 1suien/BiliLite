# 19 本机构建 0.4.12 —— 专注目标多提醒、习惯打卡心得、周课表

> 这是**本仓库自己的功能新增**，上游（官方 BiliLite）没有。三个需求是一起提的，涉及 6 个新文件 + 6 个改动文件 + 2 个新的验收脚本；改动完成后重新出了 APK：`BiliLite-0.4.12-debug.apk`（versionCode 16 / versionName 0.4.12）。

## 1. 用户需求

> 1 专注项目可以设置多个提醒时间
> 2 习惯打卡，提醒不生效无右下角弹窗提醒 点击打卡弹出 打卡心得
> 3 新增课表功能

配的截图是「编辑习惯」弹窗（习惯名 / 目标天数 / 到点提醒 09:35 + 「提醒我」勾选框）—— 说明习惯的提醒时间早就能填，但到点什么都不会发生。

动手前确认了三件事（用户答复）：

| 问题 | 选择 |
|---|---|
| 课表要哪种 | **周课表 + 关联学习**：课程可以挂 B 站视频 / 专注目标，到点提醒去学 |
| 打卡心得怎么存 | **可选填，保存进这条打卡记录，打卡日志里能看到** |
| 提醒的形式 | **右下角卡片弹窗，不自动消失，可点「去打卡 / 去专注」或关闭** |

## 2. 「提醒不生效」的原因

`app/src/stores/habits.ts` 里的提醒其实是跑着的（`startReminders()` 每 30 秒扫一次），但到点只做了两件事：

1. `notify()` —— 走 Web Notification，**安卓 WebView 拿不到通知权限，直接静默失败**；
2. `useUiStore().toast(..., 'info', 6000)` —— 一条 6 秒后自动消失的 toast，还是从屏幕上方出来的，并不是「右下角弹窗」，容易被忽略。

所以从用户的角度看就是「提醒不生效」。这一版把提醒统一改成右下角的**常驻卡片**（`components/ReminderCards.vue`），并且同一个提醒一天只弹一次。

### 3.1 专注目标：多个提醒时间

`FocusTarget.reminders` 存 `HH:MM` 数组（最多 8 个，自动排序去重）。UI 在目标行右侧多了一个小钟按钮，点开是一个弹层：

- 已设的时间以 chip 显示，chip 上的 × 删掉这个时间；
- `<input type="time">` + 「添加时间」再加一个；
- 没设过提醒的目标不显示角标，设了以后按钮上显示 `1` / `2` …

提醒由 `stores/remind.ts` 的 `dueFocus()` 扫描：遍历所有未归档目标，`time <= 当前时间` 且今天没弹过 → 弹卡片「该专注「X」了」，按钮「去专注」跳到学习页。

### 3.2 习惯打卡：打卡心得

- 点「打卡」不再直接写库，先弹「打卡心得」弹窗：可写一句心得（≤200 字），也可以点「直接打卡」留空。
- 心得存进 `habitLogs.note`（这个字段本来就有，只是以前没地方填）。
- 打卡日志里在习惯名后面跟一句灰色的心得（太长会省略，`title` 里有全文）。
- 已打过卡的再点一次「已打卡」→ 直接取消打卡（不弹心得）。
- 从提醒卡片点「去打卡」会带 `?h=<习惯id>`，习惯页会直接选中那个习惯。
- 提醒只在**今天还没打卡**的习惯上触发（原来 `dueReminders` 就是这么过滤的），打过卡就不再提醒。

### 3.3 课表

- 侧栏「课表」（`/schedule`）：7 列周视图，今天那列高亮；顶部「今天要上」按开始时间列出今天的课。
- 每张课程卡：起止时间、课程名、地点 · 老师、提醒标记、关联目标、关联视频（点「去视频」直接进播放页）。
- 编辑弹窗字段：课程名、星期、开始/结束、地点、老师、关联专注目标（下拉）、关联 B 站视频（BV 号或链接，自动抠 BV 号）、到点提醒（开关 + 提前 0/5/10/15 分钟）、备注。
- **0.4.14 起课表已精简**：地点 / 老师 / 开始结束时间 / 提前分钟都删了，只留一个「提醒时间」（`Course.remindAt`，Dexie `courses` 升 v9），见 [21-课表精简与通知声音.md](21-课表精简与通知声音.md)。
- 改开始时间时如果结束时间不比它晚，会自动顺延 45 分钟。
- 提醒由 `dueCourses()` 扫描：今天星期匹配 + 开了提醒 + 到了 `开始时间 - 提前分钟`（到开始后 10 分钟就不再提醒）→ 弹卡片「该上课了 · 课程名」，有 BV 号就「去看关联视频」，否则「去学习页」。

### 3.4 提醒中心（三种提醒共用）

- 右下角常驻卡片，最多同时 3 张；不自动消失，点 × 或「知道了」关掉。
- 位置在 `bottom: calc(96px + env(safe-area-inset-bottom))`、`z-index: 75`，让开右下角的刷新/回顶部浮动按钮。
- 同一天同一个提醒只弹一次：`localStorage['study-bili-remind-fired']` 按天记录 key（只保留最近 7 天）。
- 扫描频率 30 秒；`check(now, day)` 可以手动传时间（验收脚本就靠这个）。
- 保留原来的系统通知尝试（真机授权了就能收到系统通知），但即使失败也不影响卡片。

## 6. 升级说明

- 与 0.4.3–0.4.11 同为 debug 签名，**可直接覆盖升级**；装过官方版需先卸载（签名不同）。

## 7. 已知限制 / 未验证

- 提醒只在**应用在前台**时弹卡片（30 秒一轮）。应用被杀掉后不会响 —— 真正的系统级定时通知需要原生 `AlarmManager` / Capacitor 本地通知插件，这一版没做。
- 没做课程时间冲突检测（同一时间可以建两门课）。
- 打卡心得只能新增/覆盖当天的，不能单独编辑历史某天的心得（重打那一天可以重写）。
- 验收都在无头 Chromium + mock 桥里做，**真机上的表现（尤其提醒卡片在平板上的位置、系统通知权限）没有实测**。
- 「提前多少分钟提醒」只支持 0/5/10/15 四档。
