# 36 · 课表两处调整实现（默认不提前提醒 + 已学习=今日专注时长）

> 0.4.31 实现。方案见 [docs/35](35-课表两处调整方案.md)（用户已拍板：老数据保留、手动补记计入、完成度按条目）。

## 一、用户拍板的 3 点

1. 老数据里已有的「提前 5 分钟」时段：**保留**，只改默认值。
2. 手动补记的专注时间：**算**进「已学习」。
3. 「完成度」：**按条目算**（已完成 / 总项数），不改成时间比例。

## 二、改动 1：默认不提前提醒

`app/src/views/ScheduleView.vue`

- 编辑抽屉默认值 `remindLead: 5` → `0`；
- 新建时段（`openCreate`）`5` → `0`；
- 表格粘贴生成（`generateFromPaste`）`5` → `0`；
- 抽屉文案：复选框「开始前提醒」→「提醒」；提前分钟输入框 `step=5` → `step=1`，后面加提示 `0 = 到点才提醒`；输入框加 `data-remind-lead`（方便验收脚本定位）。

`app/src/db/index.ts`（旧「课程」迁移成时段）`remindLead: 5` → `0`。

提醒语义不变（`app/src/stores/remind.ts`）：提醒时间 = 开始 − 提前分钟；`0` 就是开始时刻提醒；卡片/系统通知各按设置开关。

## 三、改动 2：已学习 = 今日专注时长

`app/src/views/ScheduleView.vue`

```
const focusMinutes = computed(() => Math.round(pomo.todaySeconds / 60))
...
<div class="stat"><b>{{ fmtDur(stat.learned) }}</b><span>已学习</span></div>
<div class="stat"><b>{{ fmtDur(stat.plan) }}</b><span>计划</span></div>
```

改动：

- 「已学习」数值改为 `fmtDur(focusMinutes)`，数据源 `stores/pomodoro.ts` 的 `todaySeconds`（今日专注记录秒数合计，含手动补记）；
- 加了 `title` 提示：「今日专注记录合计（开始专注与手动补记都计入）」；
- 「计划」与「完成度」不变。

**踩到的坑**：`fmtDur()` 只吃**分钟**，`todaySeconds` 是**秒**——第一版直接传秒，显示成「195 小时」（验收脚本当场抓到）。统一在 `focusMinutes` 里除 60。

## 四、验收（`tools/browser/check-schedule.mjs`，从 29 项扩到 33 项）

新增：

1. 编辑抽屉 `[data-remind-lead]` 默认值是 `0`；
2. 往 IndexedDB 的 `focus` 表塞 30+90 分钟记录后，「已学习」显示随专注记录变化（不是课表估算）；
3. 「已学习」数值 ≠ 「计划」数值（口径确实换了）；
4. 只勾课表不点专注时，「已学习」不涨（不虚增）。
