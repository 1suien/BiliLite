# 删顶栏 + 标题区折叠方案（基于 0.4.44 基线 / 0.4.54）

> 当前基线：0.4.54（App 代码 = 0.4.44）。此前的 0.4.47/0.4.48 做过同类改动，但已随回退撤销；这次在 0.4.44 结构上重做。

## 1. 删除右上角两个按钮

- 位置：`app/src/App.vue` 顶部 `<header class="top">` 里的「剧场模式 F」与「‹ 返回」；
- 做法（默认：**全局删**，和上次选择一致）：整块 header 删掉，所有页面内容上移 56px；播放页标题自然贴近播放器；
- 剧场模式功能不丢：`F` 键仍可进入，进入后有「退出剧场」按钮；Esc 退出；
- 影响检查：学习/课表/收藏/设置页顶部留白需要一起调（去掉 header 后 padding 统一）。

## 2. 视频下方标题区「点击折叠 / 再点收起」

0.4.44 的结构是「标题 + 操作按钮」挤在一块（两行）。方案：

- **默认折叠**成一整行：`▸ 新概念英语 第三册 更新至47课 | 胶学 x 刘羽Leo           展开 ⌄`
  - 单行省略号截断；行尾「展开 ⌄」；
  - 点击这一行任意位置也能展开（不只点「展开」两个字）；
- **展开后**：标题（可折行）+「正在播放：P28…」+ UP/BV/时间 + 操作按钮（收藏/关注/加入学习清单/学习面板/小窗）整块出现，标题行右端显示「收起 ⌃」；
- 点「收起 ⌃」或再点一次标题行 → 收起；
- 折叠状态记 localStorage（`study-bili-video-head-collapsed`，默认关闭=折叠），下次进视频保持；
- 折叠只影响这±区，不影响 tabs（简介/笔记/相关推荐/评论）和评论。

## 4. 验收

- 任意页面顶部无「剧场模式/返回」按钮；F 仍能进剧场模式；
- 视频下方默认一行折叠条；点它/展开 → 出现完整标题+操作；再点/收起 → 回一行；
- 刷新后折叠状态保持；切分P 不重置状态。
