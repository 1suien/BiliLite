# 头像快捷菜单（本机 0.4.40）

## 做了什么

点击侧栏左下角的用户卡（头像 + 昵称），在卡上方弹出快捷菜单：

```
本地      /local
UP 管理    /ups
收藏      /fav
设置      /settings
────────────
退出登录
```

- 菜单顺序 **跟随侧栏显示顺序**（主区在前、更多区在后），并跟随导航拖拽排序；
- 当前所在页面对应项高亮（品牌色 + 浅底）；
- 未登录时底部换成「扫码登录」；
- 点菜单项自动收起并跳转；点外部、再点用户卡、按 `Esc` 也收起；
- 用户卡 hover / 打开时有浅底反馈。

## 实现

| 文件 | 改动 |
| --- | --- |
| `app/src/App.vue` | 新增 `userMenuOpen` / `userMenuPos` 状态、`userMenuItems` 计算属性（由 `mainNav` + `moreNav` 过滤 `/local /ups /fav /settings`）；`placeUserMenu()` 用 `getBoundingClientRect` 计算 fixed 定位（窄屏自动夹在视口内）；document `pointerdown` / `keydown(Esc)` / `resize` 监听；`Teleport` 到 body 渲染浮层，避免侧栏裁切 |
| `app/src/styles/global.css` | `.side-user` 可点击态、`.user-menu` / `.user-menu-item` / `.user-menu-sep` 样式（暗色主题、12px 圆角、阴影） |

无新接口、无新依赖；侧栏原有入口全部保留。

## 验收（浏览器 mock 实测）

- 点击用户卡 → 菜单出现，项顺序：本地 / UP 管理 / 收藏 / 设置 / 退出登录 ✅
- 点「设置」→ 跳转 `#/settings` 且菜单收起 ✅
- Esc 关闭 ✅
- 窄屏由 `placeUserMenu` 夹取，不超出视口 ✅
