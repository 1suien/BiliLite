
## 方案 C（已出图：06-learn-layout-c.png）

顶部一张横跨的「专注大卡」（左：目标列表；右：大圆环计时 + 暂停/完成/跳过；底部：今日概览 4 个数字），
下面左 2/3「学习进度 / 学习清单」，右 1/3「专注记录」（限高滚动）。

## 方案 C2（用户要求：今日番茄一排提到最上面，07-learn-layout-c2.png）

在 C 的基础上把「今日番茄 / 今日专注 / 总番茄 / 总专注时长」这一排数字**从专注卡底部移到页面第一行**，
独立成一张横卡，下面才是专注卡（其余不变）：

```
┌ 今日番茄 1轮 │ 今日专注 17m │ 总番茄 8轮 │ 总专注时长 2h6m ┐   ← 第一行
├──────────────────────────────────────────────────────────────┤
│ 专注目标（左：任务列表 / 右：大圆环 50:20 + 暂停·完成·跳过）    │   ← 专注卡
├────────────────────────────────────────────────────────────────┤
│ 学习进度(4)/学习清单(0) 列表（左 2/3）  │ 专注记录（右 1/3，限高）│
└────────────────────────────────────────────────────────────────┘
```

- 第一行 4 个数字横排等宽，独立卡片，一眼看到今日状态；
- 专注卡因此变矮，视线路径变成「状态 → 正在做什么 → 进度/记录」，页面顶部不压抑；
- 其余（专注卡内容、下排两栏比例、限高滚动、空状态、窄屏单列）与 C 相同。
