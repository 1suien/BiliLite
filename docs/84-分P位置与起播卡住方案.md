# 分P 弹层位置 + 起播卡住 方案（本机 0.4.63）

## 一、分P 列表改到按钮左边

现状：`分P 155 ▾` 在工具栏最右侧，弹层向右展开 → 一半屏幕外/被裁，列表被压窄。

改法：

- 弹层改成**右对齐、向左展开**：`.parts-menu { right: 0; left: auto; }`，宽度 400px，和按钮右边缘对齐；
- 高度上限 `min(60vh, 480px)`，内部滚动；
- 窄屏（< 720px）改成底部抽屉（全宽、圆角上沿、可下滑关闭）；
- 点外部 / Esc / 再次点按钮关闭（现有逻辑保留）。

## 二、起播卡住（还在「缓冲中…」）

截图数据：`地址 0.2s · 首块 0.4s · 首帧 16.4s · append 46次 · 5.2MB`——数据早就到了、缓冲也有 5 MB，但画面一直不出来。这和 0.4.32 修过的「起播慢」是同一类：**数据到了但 `video.play()` 没生效**（安卓 WebView 把非用户手势的自动播放拦掉），而现在的兜底只有一行小字提示，容易被忽略。

### 第一步：先看得见（诊断）

- 调试行补三列：`可播`（canplay 时刻）、`播放`（play 的 resolve 时刻）、`播放错误`（`NotAllowedError` / `AbortError` 等名称）；
- 状态行在「有数据 + 可播 + 仍暂停」超 2.5 秒时，直接显示**大号按钮遮罩**：「▶ 点一下开始播放」（点哪都能播）。

### 第二步：自动尝试静音起播

`ensurePlaying()` 失败时按顺序试：

1. 正常 `play()`；
2. 若被拒（`NotAllowedError`）→ 设 `muted = true` 再 `play()`（安卓 WebView 允许静音自动播放），成功后 **2 秒还原静音状态**（用户若手动调过音量则不动）；
3. 仍失败 → 保留大按钮遮罩，并停止继续拉流（省流量），点按钮后恢复。

设置里加一项「起播先静音再恢复」（默认开），可关。

### 第三步：首帧统计修正

- `首帧` 只在真正 `playing` 时记录（现在会在 `load()` 里先记一次，导致 16.4s 这种数字来源不明确）；
- 超过 8 秒没有 `playing`：状态行改「线路在但没播起来，点一下画面（或自动静音重试中）」，不再写「缓冲中…」。

## 改动文件

- `app/src/views/VideoView.vue`：分P 弹层定位样式、起播遮罩、`play()` 失败分支（含静音重试与恢复）、调试行字段；
- `app/src/player/dash.ts`：`ensurePlaying()` 增加「返回失败原因」；`tPlay` 只在 playing 时写；新增 `playError` 记录；
- `app/src/styles/global.css`：`.parts-menu` 右对齐 / 窄屏抽屉、`.play-mask` 大按钮遮罩；
- docs/84（本文）

## 验收

- 分P 弹层：点开后左边缘在工具栏内、不超出屏幕；155 P 能滚；点外部关闭；
- 起播：正常视频照旧秒开；被自动播放策略拦住时 2.5 秒内出现大按钮，点一下立刻播；开了「静音起播」时约 2 秒内自动出画面；
- 调试行能直接看到 `播放错误=NotAllowedError` 这类信息。

## 三个默认（不回就按这个）

1. 分P 弹层右对齐（向左展开），窄屏用底部抽屉；
2. 起播被拦时「静音试播 → 2 秒恢复」默认开，可关；
3. 遮罩按钮文案「▶ 点一下开始播放」，点画面任意位置生效。

## 实现（0.4.63）

- 分P 弹层：`.parts-pop` 右对齐（`right:0; left:auto`）、宽 400、`max-height: min(60vh,480px)`、`max-width: calc(100vw - 32px)`；窄屏 `@media (max-width:720px)` 变底部抽屉。
- 起播遮罩：`showPlayMask` + 2.5 秒定时检查（`readyState >= 2` 且仍 paused 且无错误）→ `.play-mask`「点一下开始播放」，点击 `startFromMask()`（取消静音 + 立即 play）；`playing` 后自动隐藏。
- 静音试播：`dash.ts` 的 `ensurePlaying()` 在首次被拒后设 `video.muted = true` 重试，成功后 2 秒恢复声音；被拒错误名写入 `stat.playError`。
- 调试行新增 `播放错误 NotAllowedError` 这类字段。
- 6 秒仍无画面：状态文案改为「线路在但没播起来：点一下画面（或等自动静音重试）」并同时弹遮罩。
