# 播放页第二版：清晰度进播放器、分P 变 tab（本机 0.4.45）

## 改了什么

### 1. 清晰度从右栏搬进播放器

- 播放器**右上角**有半透明档位标签（如 `1080P+ ▾`），点它打开清晰度菜单；
- 播放器**控制条右侧**也有一个 `清晰度` 按钮（和倍速/字幕/音量排一起），点开同一个菜单；
- 菜单里：当前档打勾「当前」，未登录时高分辨率档显示「登录」灰字（沿用 `isLocked()`）；
- 选中后立即切换（沿用 `selectQuality()`，会写进设置里的默认清晰度）；
- 右栏原来的「清晰度」卡片删除。

### 2. 分P 列表变成「简介」右边的 tab

tabs 现在是：

```
简介   分P（155）   笔记（0）   相关推荐   评论（4620）
```

- 「分P」页里是原来的完整列表：筛选框（分P 超过 12 个才出现）、按 `L001/L002` 自动分组、「跳到当前」、当前 P 高亮；
- 默认还是打开「简介」，切分P 不刷新整页。

### 3. 布局

- 右栏清空 → 播放页改**单栏**：视频按 16:9 拉满内容区宽度（`global.css` 的 `.watch` 从 `1fr 322px` 改成 `1fr`）；
- 窄屏自动单列，不需要额外适配。

## 改动文件

| 文件 | 改动 |
| --- | --- |
| `app/src/views/VideoView.vue` | 播放器加档位标签/清晰度菜单；控制条加清晰度按钮；tabs 加「分P」并接 `PartList`；删除右侧 `<aside>`；`menuOpen` 纳入清晰度菜单（点空白处关闭）；`onStagePointerDown` 不接管档位标签的点击（否则被当成播放/暂停手势） |
| `app/src/styles/global.css` | `.watch` 改单列；新增 `.q-badge`、`.q-ctl`、菜单锁定项样式 |
