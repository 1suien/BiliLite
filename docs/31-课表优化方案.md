# 课表优化方案（只要「能看要干什么」）

> 状态：界面稿 + 方案，**未改任何代码**。
> 配图：`docs/mockups/01-today.png`（今日）、`02-week.png`（全周）、`03-edit.png`（编辑时段）、`04-paste.png`（从表格粘贴）。

## 1. 为什么改

现在的课表（0.4.12 起）本质是「周课表卡片 + 到点提醒」：一门课 = 名字 + 星期 + 一个提醒时间。
你真正要的是**抬头就知道现在该干什么、还剩多久、下一个是什么**，而且你的计划本身就是
「学习 45 分钟 / 冥想 5–15 分钟」交替的时间块（早晨 → 上午 → 下午 → 晚上）。

所以把「课表」从**卡片列表**改成**时间块日程**，并把「现在」放到页面第一屏。

## 2. 新的信息模型

一个「时段」= 一条计划：

| 字段 | 说明 |
| --- | --- |
| 做什么 | 新三 / 冥想 / 阅读 / 跟读 …（必填） |
| 类型 | 学习 / 休息（休息不统计学习时长，颜色更淡） |
| 开始 / 结束 | `HH:mm`，同一行两格；结束必须晚于开始 |
| 星期 | 可多选，默认周一至周五（一份计划复制 5 天） |
| 关联（可选） | 专注目标（沿用现有 focusTargets）/ B 站视频（沿用现有 bvid） |
| 提醒 | 开始前 N 分钟弹右下角卡片（默认 5，沿用现有提醒机制）；开始时刻可选系统通知 |
| 备注 | 可选 |

派生字段（不用手填）：上午/下午/晚上/早晨 的**分段标题**由时间自动归组；
今日学习总时长、已完成项数、当前项、下一项都从时段实时算。

## 3. 四个界面

### ① 今日（默认页，回答「现在干什么」）

```
┌ 课表  10月30日 周四 · 学习日 · 今日 18 项 · 学习 6 小时 30 分   [今日|全周] [＋添加时段] ┐
├──────────────────────────────────────────────┬───────────────────────────────┤
│ [·现在进行中]  新三                 ╭────╮  │ 今日进度  5/18  2:40  6:30     │
│  09:05 – 10:50 · 学习 105 分钟      │1:18│  │ 完成度 28%  ▓▓░░░             │
│  [开始专注] [跳过这一项]            ╰────╯  │                               │
│  下一项 10:50–11:00 休息 · 冥想 · 1小时18分后  │ 接下来 10:50 冥想 / 13:00 新三 │
├──────────────────────────────────────────────┤                               │
│ 早晨 06:00–08:00                             │ 快速操作：                    │
│  06:00–06:15 跟读 15 分钟                ✓   │  从表格粘贴今天的计划          │
│  07:00–07:45 新三 45 分钟                ✓   │  应用「学习日」模板            │
│  07:45–08:00 冥想 休息                   ✓   │  整体提前/延后 15 分钟         │
│ 上午 08:00–11:00                             │ 提醒：开始前 5 分钟 / 开始时刻  │
│  08:00–08:45 新三 45 分钟                ✓   │                               │
│  08:45–09:05 冥想 休息                   ✓   │                               │
│  09:05–10:50 新三 105 分钟  ← 进行中（蓝底）  │                               │
│  10:50–11:00 冥想 休息                   待开始│                               │
│ 下午 13:00–16:50  （滚动，底部渐隐）           │                               │
└──────────────────────────────────────────────┴───────────────────────────────┘
```

要点：
- **当前项最大**：34px 名字 + 进度环（剩余时间、已过百分比），不用点任何东西就知道在干嘛。
- 每个时段三种状态：`✓ 已完成`（灰）/ `进行中`（蓝底 + 呼吸点）/ `待开始`；下一项那行用浅色标记。
- 「开始专注」直接跳学习页并带上关联目标（复用现有专注计时），「跳过」只改状态不计时。
- 到点前 5 分钟，右下角弹提醒卡片（复用 ReminderCards），点卡片 = 切到本页并高亮该项。

### ② 全周（看整周安排）

- 7 列，每列按时间排的色块；学习实底、休息虚线，今天那列高亮、当前块蓝色。
- 列头显示「18 项」，底部「… 还有 8 项」展开；点任意块 → 打开编辑弹层。
- 顶部可切换上一周 / 下一周（暂不做「多套课表」，先把一周做好）。

### ③ 编辑时段（右侧抽屉）

- 做什么 / 类型（学习·休息二选一）/ 起止时间 / 星期多选 / 关联目标·视频 / 两个提醒开关 / 删除。
- 同一天里自动校验重叠：和前一段冲突时提示「与 08:45–09:05 冥想重叠，是否顺延？」。

### ④ 从表格粘贴（把 WPS 里那张表一次搬进来）

- 直接复制 WPS 四列「开始 · 结束 · 做什么 · 类型」；没有类型列时按关键词判断（冥想/休息/运动=休息）。
- 自动跳过表头、「上午/下午」分隔行、空行；右侧预览识别结果和总项数。
- 选星期（默认一~五）→ 一键生成（示例：18 项 × 5 天 = 90 个时段）。
- 也可先「清空今天的计划」再粘贴。

## 4. 与你现有功能的对接（实施时才会动代码）

| 现有能力 | 怎么接 |
| --- | --- |
| 课程/提醒（`stores/courses.ts`、`stores/remind.ts`、`ReminderCards`） | 时段表替换「课程=提醒时间」的模型；提醒扫描改为「开始前 N 分钟」，卡片文字用「10:50 冥想 · 休息 10 分钟」 |
| 专注目标（`settings.focusTargets`）、专注计时 | 「开始专注」带入选中的 target；完成一项后回写该时段状态=已完成 |
| B 站视频（bvid） | 关联视频的时段在「进行中」卡片上多一个「去视频」按钮，沿用现有跳转 |
| 学习页统计 | 今日学习时长 = 类型=学习的时段中已完成部分之和（进行中按已过时间算） |
| 本地存储（Dexie） | 新增一张表存时段；旧 courses 数据一次性迁移成「只带提醒时间」的时段，不丢数据 |

## 5. 分期

- **P0（先做）**：今日页（现在卡 + 时间轴 + 状态）、编辑弹层、全周页只读、提醒联动。
- **P1**：从表格粘贴、学习日模板、整体顺延、周切换。
- **P2**：拖动改时间、完成率周统计、和习惯打卡/专注记录打通。

## 6. 验收标准

1. 打开课表，1 秒内能看到「现在做什么 + 还剩多久 + 下一项是什么」。
2. 一天 18 个时段在平板上一屏能看到上午之前的部分，滚动顺滑，当前项始终可见。
3. 新建/编辑/删除时段，今日页与全周页同步刷新。
4. 粘贴 WPS 四列能一次生成整周时段，识别结果可预览、可撤回。
5. 到点前 5 分钟出提醒卡片，点卡片回课表并高亮该项。
6. 旧课表数据迁移后不丢失，历史提醒不再重复弹。

## 7. 需要你拍板的三件事

1. **学习/休息是否分开算**：休息块不计入「今日学习时长」，只做节奏提示 —— 同意吗？
2. **默认提醒提前量**：5 分钟够不够？要不要每段单独设？
3. **是否保留「课程」这个概念**（课程名 + 教师/地点），还是完全按时间块来 —— 我的建议是**完全按时间块**，把「课程」删掉，减少概念。
