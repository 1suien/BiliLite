# 04 · 数据层与本地存储

本地数据分两类：**IndexedDB（Dexie，库名 `study-bili`）** 存学习/习惯/本地视频等业务数据；**Capacitor Preferences（key `bililite.state.v1`）** 存设置、登录用户、Cookie。另有少量纯前端状态写 `localStorage`。

## Dexie：`study-bili`

`app/src/db/index.ts`（554 行）。库名与全部表名、索引、版本演进都从产物里原样照抄——**不能改**，否则从旧版升级的用户会丢数据。

### 访问函数（导出清单）


## Preferences：`bililite.state.v1`

`app/src/bridge/state.ts`（245 行）。整个持久化状态是**一个 JSON**，写入 Capacitor Preferences（原生 SharedPreferences），失败回退 `localStorage`：

```ts
{
  settings: { /* 18 项默认设置 */ },
  user: { isLogin, mid, uname, face, level, ... } | null,
  cookies: { SESSDATA, bili_jct, DedeUserID, DedeUserID__ckMd5, ... }
}
```

- **敏感字段编码**：Cookie 值统一存成 `"raw:" + btoa(value)`，读出时解码（原产物就是这么做的，属于混淆而非加密）；
- **设置默认值**（`DEFAULT_SETTINGS`，与原 `ie` 对象逐项一致）：`theme:'dark'`、`accent:'mono'`、`defaultQuality:80`、`autoNext:true`、`seekStep:5`、`playerVolume:0.8`、`autoCheckin:false`、`playbackRate:1`、`danmakuOn:true`、`danmakuOpacity:0.9`、`danmakuArea:1`、`autoHideCtl:true`、`navOrder:[]`、`subAuto:false`、`subFontSize:22`、`subBg:true`、`subBottom:8`、`focusTasks:['阅读','刷题','看课','整理笔记']` 等（弹幕相关键是早期版本遗留，0.4.3 的 UI 已不暴露）；
- **API**：`load()`、`persist()`、`patchSettings(patch)`、`setUser(user)`、`clearAuth()`、`isLoggedIn()`、`splitSetCookie()`、`applySetCookie()`；
- 登录成功后把 passport 返回 URL 里的 `DedeUserID` / `DedeUserID__ckMd5` / `SESSDATA` / `bili_jct` 提出来存进 `cookies`，之后所有请求由 `http.ts` 带上。

## 学习时长的写入路径（最容易出错的地方）

```
播放器 onTime（每 1s）→ VideoView 本地累计
        ↓ 每 5s / visibilitychange / beforeunload
learn.addSeconds(sec, upName)
        ↓
db.addDailySeconds(today, sec)     // 每日总时长
db.bumpDailyVideo(today)           // 当日视频数（开始播放时）
db.addUpSeconds(mid, upName, sec)  // 按 UP 汇总
db.putProgress({...})              // 分P 进度 + completed
        ↓
learn store 内存同步 → 首页「继续学习」/ 学习页统计刷新
```

番茄钟（`pomodoro`）走另一条路：一轮结束 → `db.addFocusSession()` 写 `focus` 表，学习页的「概览/记录」直接读这张表。

## 备份 JSON 格式（设置页 / 学习页「导出 JSON」）

```json
{
  "app": "study-bili",
  "version": "0.1.0",
  "exportedAt": 1730000000000,
  "user": { "isLogin": true, "mid": 14871346, "uname": "…" },
  "progress": [...],
  "daily": [...],
  "notes": [...],
  "shelf": [...]
}
```

写盘由桥完成：`bili.backup.write(dir, name, text)` → Android 上先尝试 Documents 再降级 Cache，然后弹系统分享面板（原文案「…（已打开「保存到」面板，可另存到任意位置）」）。文件名 `bililite-learn-<ISO 时间，: 和 T 换成 ->.json`（如 `bililite-learn-2026-10-03-12-15-00.json`）。
