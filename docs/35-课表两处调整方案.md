# 35 · 课表两处调整方案（默认不提前提醒 + 已学习=今日专注时长）

> 方案稿（已按用户拍板实现，见 [docs/36](36-课表两处调整实现.md)）。基于 0.4.30（`f093137`）现状。

## 一、需求

1. **默认不设置提前提醒**：新建/粘贴生成的时段，默认「提前 0 分钟」，即到点才提醒（要提前的人自己改）。
2. **今日进度里的「已学习」改成今日专注时长**：现在显示的是课表里已勾/进行中时段的计划时长之和（估算），要改成真实的专注记录合计。

## 二、改动一：默认不提前提醒

| 位置 | 现在 | 改成 |
|---|---|---|
| `app/src/views/ScheduleView.vue:231` 编辑抽屉默认值 | `remindLead: 5` | `remindLead: 0` |
| `app/src/views/ScheduleView.vue:251` 新建时段（applyHeader / 快捷添加） | `remindLead: 5` | `remindLead: 0` |
| `app/src/views/ScheduleView.vue:374` 表格粘贴生成 | `remindLead: 5` | `remindLead: 0` |
| `app/src/db/index.ts:820` 旧「课程」迁移成时段 | `remindLead: 5` | `0` |
| 编辑抽屉文案 | 「提前 分钟」 | 「提前提醒（0 = 到点才提醒）」 |

语义不变（`app/src/stores/remind.ts:148` 与 `:250`）：提醒时间 = 时段开始 − 提前分钟，`0` 就是开始时刻提醒；卡片和系统通知各按设置开关。

**老数据**：不动。之前建好的时段如果设了 5 分钟，保留 5——只改「默认值」，不做批量改写。要一键清零的话另说。

## 三、改动二：已学习 = 今日专注时长

现在（`app/src/views/ScheduleView.vue:533`）：

```
已学习 = stat.learned  // stores/slots.ts statOf()：已勾时段/进行中时段的计划时长之和
```

改成：

```
已学习 = pomo.todaySeconds  // stores/pomodoro.ts:198：今天所有专注记录（含手动补记）的秒数合计
计划   = stat.plan          // 课表里今天学习时段的计划总时长（不变）
完成   = stat.done / stat.total（不变）
完成度 = done / total（不变，仍按条目算，不随专注时长变）
```

- 第三格「计划」保持不变，一眼能看出「计划 8 小时 35 分 / 实际专注 4 小时 59 分」的差距。
- 「已学习」格下面加小字「专注」区分口径（`今日进度 2 小时 40 分 专注`）。
- `onMounted` 里已有 `pomo.init()`；补一个 `pomo.loadStats()` 兜底，保证从学习页切回来时数字是新的。
- 数据源是 `pomodoro` 的 sessions（今日记录合计）：
  - 自然到点完成 / 手动完成 / 跳过按部分完成，都按实际秒数计入；
  - **进行中不预结算**（和番茄规则一致，结束时才落库）；
  - 手动补记（学习页「补记」）计入——它就是真实专注时间。

**边界/诚实性**：没点过专注 → 已学习显示 0 小时 0 分（即使课表全勾完）。这是想要的效果：数字反映真实专注，不反映「计划完成」。

## 五、验收（加进现有脚本）

- 新建时段 / 粘贴生成后，DB 里 `remindLead === 0`；
- 编辑抽屉默认显示 0；
- 今日进度「已学习」= 今日专注记录合计（测试里造两条记录：30 分 + 90 分 → 显示 2 小时 0 分）；
- 不点专注、只勾完成 → 已学习仍是 0（不虚增）；
- 全周/时间轴/开始专注不受影响（现有 29 项断言全过）。
