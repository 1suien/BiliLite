## 外壳（`App.vue`，361 行）

- **左侧导航**：学习（右侧显示今日时长 `0.68h`）、习惯、课表（0.4.12 新增）、本地 —— 本机 0.4.9 删除了「首页」，侧栏第一项现在是学习 —— 之后一条分割线 —— UP 管理、收藏、设置（这三项属于 `nav.side-more` 分组），底部是用户卡（头像/昵称/等级）与「退出登录 / 扫码登录」按钮。
- **顶部栏**：搜索输入（占位「搜索视频 / 知识点，回车确认（按 `/` 快速…）」，回车跳 `/search?q=…`）、搜索按钮、今日时长、`剧场模式` 按钮、更多按钮。
- **导航排序**：设置里的 `navOrder` 支持拖动排序，但**只在同一组内互换**（main 区 ↔ main 区、more 区 ↔ more 区），与产物一致。
- **快捷键**：`F` 切换剧场模式；`Esc` 退出剧场；`/` 聚焦搜索框。
- **刷新机制**：`<RouterView :key="route.fullPath + '#' + ui.refreshSeq" />`，没有 keep-alive；`ui.refreshSeq++` 会重建当前页面（设置页「恢复默认」后用到）。
- **路由 watch**：离开页面时自动退剧场模式并滚回顶部。
- **全局挂载物**：`Toasts`（右上角堆叠提示）、`LoginModal`（扫码登录）、`ConfirmModal`（`ui.confirm()` 的 Promise 确认框）、`PageFloat`（页面右下浮动刷新按钮）、`MiniPlayer`（小窗播放，圆形气泡）、`ReminderCards`（0.4.12 起：到点提醒卡片，习惯/专注/课表共用；**0.4.13 起贴在屏幕最右下角**，出现时右下角刷新浮钮自动让位）。

### 播放 `VideoView`（1660 行）

应用里最重的页面，组件：`PartList`（254 行，分 P 列表 + 「跳到当前」）、`CollectModal`（164 行，收藏到文件夹）、`Icon`、`BiliImage`。

- **播放器**：`createDashPlayer(videoEl, hooks)`（`player/dash.ts`，1446 行）——自研 DASH/MSE 内核，mpegts.js 兜底 FLV/TS；自定义控制条（播放/暂停、上/下一分P、时间、进度条、倍速、字幕开关、音量、全屏），无控制条自动隐藏；起播、切换清晰度（`quality.ts` 的 240P…8K/智能修复/杜比视界）、失败重试面板（原文案「这条线路暂时拿不到数据」「重新获取播放地址」「在浏览器打开」）。
- **信息区**：标题、UP 头像/昵称（点进 `/up/:mid`）、BV 号（可复制）、发布时间、`已收藏`/`加入学习清单`/`学习面板` 三个文字按钮 + **圆形图标按钮「小窗播放」**（`button.mini-entry`，本机定制 0.4.7 起由文字按钮改成圆形入口）、`收藏` 打开 `CollectModal`。
- **tab**：简介（含 `bili.video.view` 的 desc，超长折叠）、笔记（本地 `db.notes`，**按分P独立**；本机构建 0.4.5 起为多行 textarea：回车换行、Ctrl+Enter 或点「保存」写入，见 [12](12-笔记按分P独立.md)；0.4.7 起笔记行只剩「正文 + 最右侧删除」，没有跳转按钮，见 [14](14-小窗圆形气泡与笔记行按钮.md)）、相关推荐（`bili.video.related`，视频卡网格）。
- **数据**：`video.view`（详情/分P）、`video.pages`、`video.playurl`（DASH 或 durl）、`video.related`、`video.online`（在线人数）、`video.subtitle`（字幕轨道，最多 5 条，支持本地外挂 `sys.readSubtitle`）；
- **播放进度**：每 5 秒（及 `visibilitychange`/`beforeunload`）写 `learn.addSeconds(sec, upName)` + `db.putProgress`，用于学习页统计（原首页「继续学习」入口已随首页删除）；**0.4.11 修**：离开播放页时 `flushProgress()` 之前拿到的 bvid 来自 `route.params`，离开瞬间已变空串导致这次落库被丢弃，现在改用本页实例的稳定 bvid（`openedBvid`），退出前的真实位置能存住（见 [18](18-退出后继续上次进度.md)）；
- **自动连播**：`settings.autoNext` 时 `ended` → 下一分P / 相关推荐第一个；
- **剧场模式**：`html[data-fullscreen]` + `App` 的 `.theater` 类（由 `installFullscreen()` 驱动沉浸式、状态栏、横屏）；
- **小窗**：点圆形入口调 `mini.play({...})` 后本页暂停，右下角出现**圆形气泡**（本机定制 0.4.7：原来是可缩放的长方形小窗）；气泡可拖动、跨页面常驻，点气泡＝回到本页并带当前进度继续看，右上角 × 关闭（见 [14](14-小窗圆形气泡与笔记行按钮.md)）。**0.4.8 起**：任何页面切换（点左侧导航、首页卡片、返回）离开播放页时，视频**自动缩成右下角小圆并暂停**，点小圆回播放页从暂停处自动继续播；同页换分P/换视频、刷新、拉流失败不触发（见 [15](15-离开播放页自动暂停小窗.md)）。**0.4.11 起**：如果直接从学习页/搜索再打开同一条视频，页面会**把小窗自动收回本页并从离开的位置继续播**，不再只留一个「视频正在小窗播放」的占位画面（见 [18](18-退出后继续上次进度.md)）。

> **没有弹幕层**：原 0.4.3 的播放 chunk 里 `danmaku/弹幕` 出现 0 次，`dm-layer/dm-item/dm-bar` 样式虽残留在 `global.css`，但没有任何视图使用。数据桥保留了 `video.danmaku`/`video.sendDanmaku` 通道（37 个通道之一），忠实还原 = 不实现弹幕 UI。

### 设置 `SettingsView`（643 行）

本机 0.4.14 起是 5 组（与 chunk 一致，没有弹幕/字幕/navOrder 设置）：

1. **外观**：主题 chip（dark/light）、强调色色板（`ACCENTS`）、自定义 hex 输入（校验 `/^#[0-9a-f]{6}$/i`，失败回滚 + 错误提示）；

4. **提醒**（本机 0.4.14 新增）：`测试通知`（原生 `ReminderChannelPlugin.testNotification`，立刻发一条本通道通知，用来验证弹不弹/响不响）、`通知设置`（`Settings.ACTION_CHANNEL_NOTIFICATION_SETTINGS` 跳到系统里这条通道的设置页）+ 说明文案；浏览器预览里两个按钮会提示「只在安卓 APK 里生效」；
5. **关于**：版本号、外链、免责声明。

`重置设置` 只 patch 8 个键（theme/accent/defaultQuality/autoNext/seekStep/playerVolume/hideDanmakuArea/autoMark/autoCheckin）。备份内容 = `db.progress` + `db.daily` + `db.notes` + `db.shelf`，文件名 `bililite-learn-<ISO>.json`。导入（`打开 JSON 备份…`）与本文件描述的格式对称：校验 `app === 'study-bili'` 后按 key/date/bvid/内容去重**合并**（见 [docs/13](13-备份打开与导入恢复.md)）。
