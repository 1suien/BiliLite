## 外壳（`App.vue`，361 行）

- **左侧导航**：首页、学习（右侧显示今日时长 `0.68h`）、习惯、本地 —— 之后一条分割线 —— UP 管理、收藏、设置（这三项属于 `nav.side-more` 分组），底部是用户卡（头像/昵称/等级）与「退出登录 / 扫码登录」按钮。
- **顶部栏**：搜索输入（占位「搜索视频 / 知识点，回车确认（按 `/` 快速…）」，回车跳 `/search?q=…`）、搜索按钮、今日时长、`剧场模式` 按钮、更多按钮。
- **导航排序**：设置里的 `navOrder` 支持拖动排序，但**只在同一组内互换**（main 区 ↔ main 区、more 区 ↔ more 区），与产物一致。
- **快捷键**：`F` 切换剧场模式；`Esc` 退出剧场；`/` 聚焦搜索框。
- **刷新机制**：`<RouterView :key="route.fullPath + '#' + ui.refreshSeq" />`，没有 keep-alive；`ui.refreshSeq++` 会重建当前页面（设置页「恢复默认」后用到）。
- **路由 watch**：离开页面时自动退剧场模式并滚回顶部。
- **全局挂载物**：`Toasts`（右上角堆叠提示）、`LoginModal`（扫码登录）、`ConfirmModal`（`ui.confirm()` 的 Promise 确认框）、`PageFloat`（页面右下浮动刷新按钮）、`MiniPlayer`（小窗播放）。

## 各页面

### 首页 `HomeView`（219 行）

原版**没有推荐流**（`home.feed/home.popular` 只有桌面桥暴露，没有任何视图调用），页面由两块组成：

1. **继续学习**：从 `learn` store 取未看完的进度（`listByVideo` 去重后的前几项），显示封面/标题/UP/进度条；空态是「还没有学习记录」引导去搜索；右上「学习统计」跳 `/learn`。
2. **关注的 UP 更新**：`ups.latest()`（分组 UP 的最新投稿，并发请求，结果 5 分钟缓存），带「管理名单」「刷新」按钮；上方一行 UP chips（`全部 N` + 每个 UP 的投稿数），点 chip 过滤；四种状态：加载中（`SkeletonGrid`）、报错、空、有数据。

组件：`VideoCard`、`SkeletonGrid`、`EmptyBlock`、`Icon`、`BiliImage`。

### 搜索 `SearchView`（221 行）

- 顶部搜索框 + `搜索` 按钮，URL 只同步 `q`（`#/search?q=线性代数`）；
- 两个 tab：**视频**（`bili.search.videos(q, page)`）与 **UP 主**（`bili.search.ups(q)`）；
- 视频结果用 `VideoCard` 网格 + `Pager` 分页；UP 结果卡片显示头像/昵称/粉丝数/签名，点击进 `/up/:mid`；
- 空查询显示引导，空结果显示 `EmptyBlock`。

### 播放 `VideoView`（1660 行）

应用里最重的页面，组件：`PartList`（254 行，分 P 列表 + 「跳到当前」）、`CollectModal`（164 行，收藏到文件夹）、`Icon`、`BiliImage`。

- **播放器**：`createDashPlayer(videoEl, hooks)`（`player/dash.ts`，1446 行）——自研 DASH/MSE 内核，mpegts.js 兜底 FLV/TS；自定义控制条（播放/暂停、上/下一分P、时间、进度条、倍速、字幕开关、音量、全屏），无控制条自动隐藏；起播、切换清晰度（`quality.ts` 的 240P…8K/智能修复/杜比视界）、失败重试面板（原文案「这条线路暂时拿不到数据」「重新获取播放地址」「在浏览器打开」）。
- **信息区**：标题、UP 头像/昵称（点进 `/up/:mid`）、BV 号（可复制）、发布时间、`已收藏`/`加入学习清单`/`学习面板` 三个文字按钮 + **圆形图标按钮「小窗播放」**（`button.mini-entry`，本机定制 0.4.7 起由文字按钮改成圆形入口）、`收藏` 打开 `CollectModal`。
- **tab**：简介（含 `bili.video.view` 的 desc，超长折叠）、笔记（本地 `db.notes`，**按分P独立**；本机构建 0.4.5 起为多行 textarea：回车换行、Ctrl+Enter 或点「保存」写入，见 [12](12-笔记按分P独立.md)；0.4.7 起笔记行只剩「正文 + 最右侧删除」，没有跳转按钮，见 [14](14-小窗圆形气泡与笔记行按钮.md)）、相关推荐（`bili.video.related`，视频卡网格）。
- **数据**：`video.view`（详情/分P）、`video.pages`、`video.playurl`（DASH 或 durl）、`video.related`、`video.online`（在线人数）、`video.subtitle`（字幕轨道，最多 5 条，支持本地外挂 `sys.readSubtitle`）；
- **播放进度**：每 5 秒（及 `visibilitychange`/`beforeunload`）写 `learn.addSeconds(sec, upName)` + `db.putProgress`，用于首页「继续学习」和统计；
- **自动连播**：`settings.autoNext` 时 `ended` → 下一分P / 相关推荐第一个；
- **剧场模式**：`html[data-fullscreen]` + `App` 的 `.theater` 类（由 `installFullscreen()` 驱动沉浸式、状态栏、横屏）；
- **小窗**：点圆形入口调 `mini.play({...})` 后本页暂停，右下角出现**圆形气泡**（本机定制 0.4.7：原来是可缩放的长方形小窗）；气泡可拖动、跨页面常驻，点气泡＝回到本页并带当前进度继续看，右上角 × 关闭（见 [14](14-小窗圆形气泡与笔记行按钮.md)）。

> **没有弹幕层**：原 0.4.3 的播放 chunk 里 `danmaku/弹幕` 出现 0 次，`dm-layer/dm-item/dm-bar` 样式虽残留在 `global.css`，但没有任何视图使用。数据桥保留了 `video.danmaku`/`video.sendDanmaku` 通道（37 个通道之一），忠实还原 = 不实现弹幕 UI。

### 收藏 `FavView`（401 行）

- 两个区块：**本地收藏夹**（Dexie `collectfolders` + `collect`，只有新建/删除，没有重命名）+ **B 站收藏夹**（`bili.fav.folders()`，分「我创建的」与「我收藏的」，显示封面与条目数）；
- 未登录时显示登录引导（`ui.askLogin()`），已登录但接口报 `needLogin` 也走引导；
- 点文件夹 → `/fav/:mediaId`（B 站）或本地展开/进入。

### 收藏夹 `FavFolderView`（152 行）

- `bili.fav.resources(mediaId, page)` 返回 `{info, medias, hasMore}`，卡片显示封面/标题/UP/收藏时间/播放量（`cntInfo`），点击播放、点 UP 进 UP 主页；
- **卡片上没有「取消收藏」按钮**（原版就没有）；
- 底部「加载更多」按 `hasMore` 累加，顶部显示文件夹标题与条目数。

### 学习 `LearnView`（227 行）

无独立 scoped CSS（全部用 `global.css` 的 `.page-head/.stat-grid/.tabs/.rowitem/.panel` 等）。三块内容**同时平铺**：

1. **统计卡**：总学习时长、连续签到天数、本周专注时长（3 张 `.stat` 卡）；
2. **学习进度 / 学习清单** 两个 tab：进度列表（`learn.list`：封面/标题/UP/进度条/完成标记）+ 清单（`shelf` 收藏的学习视频）；
3. **今日习惯**（`HabitHome`）+ **专注目标/番茄钟**（`FocusTargets` + `FocusPanel`）+ **概览**（`FocusOverview` 4 张数字卡）+ **专注记录**（`FocusRecords` 按天分组）。

顶部按钮：`导出 JSON`（学习数据备份，同设置页的备份逻辑）与 `清空`（`ui.confirm` 后 `learn.clearAll()`）。

### 习惯 `HabitView`（699 行）

- 左侧列表：`坚持中 N` / `已归档 N` 两个 tab；每行 = emoji 脸（`sum%997%12` 哈希出彩色 emoji）+ 名称 + 7 天点阵 + `13/66` 进度 + 「已打卡」按钮/状态；点行右侧区域选中；
- 右侧详情：名称、目标天数、提醒时间、`编辑`/`归档`/`删除` 按钮、4 个 `.hb-stat`（月打卡/总打卡/月完成率/当前连续）、进度条、`目标 N 天 · 已坚持 N 天 · 最长连续 N 天`、6×7 月历（`null` 占位空格，今天高亮，可补打卡/取消）、当日打卡日志；
- 新建/编辑弹窗：名称、emoji、目标天数、提醒时间（无备注框）；
- 提醒：`stores/habits.ts` 里 30 秒轮询 + Notification（`localStorage: study-bili-habit-remind` 记录已提醒日期）；
- `清空` 按钮清空全部习惯与打卡记录。

### 本地 `LocalView`（456 行）

- 视频网格：封面（`thumb`）或占位、标题、时长、进度条、`missing` 标记（文件失联灰显 + 提示重新导入）；
- 顶部：`导入文件`（`bili.local.pickFiles()`）与 `扫描文件夹`（`bili.local.pickFolder()`）；
- 导入流程：桥返回 `android://` 伪路径 → `bili.local.register(paths)` → 用离屏 `<video>` + `<canvas>` 读时长与首帧封面（`currentTime = 1e101` hack 取末帧，部分格式失败则留空）→ 写 Dexie `locals`；重复导入保留旧 `pos`/`thumb`/`addedAt`；
- 卡片操作：播放（`/local/:id`）、移除、定位（安卓上 `local.reveal` 永远抛「安卓上没有『在资源管理器里定位』」，与原文案一致）。

### 本地播放 `LocalPlayerView`（231 行）

- 原生 `<video controls autoplay playsinline>`，无自定义控制条、无快捷键（原版就是这样）；
- `loadedmetadata` 时 seek 回 `locals.pos`；每 5 秒节流写回 `pos`；
- `error.code === 4`（不支持格式）时显示 HEVC/AV1 兼容提示；
- 返回本地列表。

### UP 管理 `UpManageView`（465 行）

- 分组管理（Dexie `upgroups`）：新建/重命名/删除分组，UP 卡片可在分组间移动；
- `导入 B 站关注`：`bili.up.followings()`（最多 6 页 × 50）→ 逐个 `up.resolve(mid)`；已存在的跳过；
- 添加 UP：输入 UID / 空间链接 / 昵称 → `bili.up.resolve(q)`；结果缺 `face` 时再 `bili.up.info(mid)` 兜底合并（try/catch 静默）；
- 每张 UP 卡显示头像/昵称/最新投稿数/更新时间，点击进 `/up/:mid`；支持移除、拖动排序（组内）。

### UP 主 `UpView`（212 行）

- `bili.up.info(mid)` 取资料（头像/昵称/签名/粉丝/等级）+ `bili.up.videos(mid, page)` 投稿列表（分页 `Pager`）；
- `关注/已关注` 按钮只写本地 `ups` 表（不改 B 站关注关系，原版如此）；
- 投稿卡片点击播放，空态 `EmptyBlock`。

### 设置 `SettingsView`（587 行）

只有 4 组（与 chunk 一致，没有弹幕/字幕/navOrder 设置）：

1. **外观**：主题 chip（dark/light）、强调色色板（`ACCENTS`）、自定义 hex 输入（校验 `/^#[0-9a-f]{6}$/i`，失败回滚 + 错误提示）；
2. **播放**：默认清晰度 chip、自动连播、快进步长（3/5/10/15 秒）、音量滑杆、自动标记已学、自动签到；
3. **数据**：备份位置（安卓只显示说明、不给假目录按钮；其它平台保留备份目录 + 选择/打开）、`写入 JSON 备份`、`打开 JSON 备份…`（导入合并恢复，见 [docs/13](13-备份打开与导入恢复.md)）、`重置设置`；
4. **关于**：版本号、外链、免责声明。

`重置设置` 只 patch 8 个键（theme/accent/defaultQuality/autoNext/seekStep/playerVolume/hideDanmakuArea/autoMark/autoCheckin）。备份内容 = `db.progress` + `db.daily` + `db.notes` + `db.shelf`，文件名 `bililite-learn-<ISO>.json`。导入（`打开 JSON 备份…`）与本文件描述的格式对称：校验 `app === 'study-bili'` 后按 key/date/bvid/内容去重**合并**（见 [docs/13](13-备份打开与导入恢复.md)）。
