# 播放页标题区折叠（本机 0.4.47）

## 效果

默认折叠，视频下面只有一行：

```
▸ 新概念英语 第三册 更新至47课 | 胶学 x 刘羽Leo        展开 ⌄
```

点这一行（整行可点）展开成原来的三段：标题、正在播放、UP/BV/时间、操作按钮；再点「收起 ⌃」收回去。

## 实现

- `app/src/views/VideoView.vue`
  - 新增 `headCollapsed`（默认 `true`，读 localStorage `study-bili-video-head-collapsed`，`'0'` 表示展开过）；
  - `toggleHead()` 切换并写回 localStorage；
  - 折叠条 `.head-collapsed`：箭头 + 单行省略标题 + 行尾「展开 ⌄ / 收起 ⌃」；
  - 原「标题块 / UP·BV·时间行 / 操作按钮行」三块加 `v-show="!headCollapsed"`。
- `app/src/styles/global.css`
  - `.head-collapsed` 样式：44px 高、卡片底、描边、hover 高亮。

不影响播放、不重新拉流；切分P 保持当前折叠状态。

## 验收

- 浏览器 mock：默认渲染折叠条（`.head-collapsed` 存在），点击后折叠条消失、`h1` 出现，localStorage 写入 `'0'`；
