# 16 本机构建 0.4.9 —— 删除「首页」

> 这是**本仓库自己的界面删减**，上游（官方 BiliLite 0.4.4）没有。0.4.5–0.4.8 的定制（笔记按分P独立、多行笔记、备份导入、圆形小窗、离开自动暂停小圆）都还在。

## 1. 用户要求

用户 m01890（原话）：

> 删除首页

我问了「删除范围」，用户选了**彻底删除**：左侧导航条目、`/` 路由、`views/HomeView.vue` 文件全删，打开 App 直接进「学习」页。

## 2. 删除前的首页是什么

`app/src/views/HomeView.vue`（219 行）是原版 APK 的第一页，两块内容：

1. **继续学习**：从 `learn` store 取最近未看完的进度，横排视频卡；
2. **关注的 UP 更新**：`ups.latest()` 拉名单里 UP 的最新投稿（5 分钟缓存），带「管理名单」「刷新」与 UP chips 过滤。

原版就没有推荐流（`home.feed`/`home.popular` 只有桌面桥暴露、没有视图调用），所以首页 = 继续学习 + 关注更新。

## 3. 改动

| 文件 | 改动 |
|---|---|
| `app/src/App.vue` | `NAV_ITEMS` 删掉 `{ to: '/', icon: 'home', label: '首页' }`；侧栏第一项变成「学习」 |
| `app/src/router/index.ts` | 删 `HomeView` 的懒加载常量；`{ path: '/', name: 'home', component: HomeView }` → `{ path: '/', redirect: '/learn' }`；兜底 `/:pathMatch(.*)*` 仍重定向 `/`（于是也落到学习页） |
| `app/src/views/HomeView.vue` | **整个文件删除**（219 行） |
| `app/src/views/VideoView.vue` | 打开失败页的「回首页」链接 → 「回学习」（`to="/learn"`）；「加入 UP 管理名单」的 title 不再提「首页」 |
| `app/src/views/LearnView.vue` | 学习记录空态的「去首页找视频」→「去搜索找视频」（`router.push('/search')`） |
| `app/src/views/UpManageView.vue` | 两处文案去掉「首页只显示…」的说法，改为「播放页可一键加入名单」「集中管理」 |
| `app/src/views/UpView.vue` | 「移除后首页不再显示 TA 的更新」→「移除后不再跟踪 TA 的更新」 |
| `tools/browser/shot.mjs` | 截图脚本的导航清单 `['首页', '#/']` → `['学习', '#/learn']` |

路由表因此变成 **11 个页面 + 1 条兜底重定向**；`#/` 和旧地址 `#/home` 都会自动落到 `#/learn`。

## 4. 影响

- **好的**：启动即学习页，少一次点击；包里少一个页面 chunk（APK 从 4,108,755 B 降到 **4,105,445 B**）。
- **要知道的**：首页删掉后，「继续学习」和「关注 UP 更新」这两个入口也没了；「UP 管理」名单仍保留、仍能增删与导入关注，但**不再有页面消费这份名单**（原来只有首页用它拉更新流）。学习记录/统计在「学习」页与播放页写进度都不受影响。
- 历史文档（[docs/02](02-路由与页面.md)、[docs/03](03-还原方法与还原度.md)、[docs/05](05-数据桥API清单.md)、[docs/08](08-与上游源码逐模块核对.md)）里描述「首页」的段落是**上游原版**的还原记录，保留作对照；本机构建以本文为准。

## 7. 升级

- 与 0.4.5–0.4.8 同为 debug 签名，**可直接覆盖升级**（versionCode 13 > 12 > 11 > 10 > 9 > 8 > 7）；装过官方版需先卸载（签名不同）。
- 数据不受影响：首页删的是视图，`learn` 进度、`notes`、`shelf`、`settings.navOrder` 都在 IndexedDB 里；`navOrder` 里若还留着 `/`（旧版本拖过排序），会被自动过滤掉。
