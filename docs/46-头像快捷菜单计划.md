# 头像快捷菜单（计划，暂未写代码）

## 需求

点击侧栏左下角的头像/用户卡，弹出快捷菜单，包含：**本地、UP 管理、收藏、设置**。

## 现状（`app/src/App.vue`）

- 侧栏主区：学习 / 习惯 / 课表 / 本地（按 `settings.navOrder` 可拖拽排序）
- 「更多」区：UP 管理 / 收藏 / 设置（`MORE_PATHS = ['/fav', '/ups', '/settings']`）
- 底部用户卡 `.side-account`：头像 + 昵称 + `LvN · 已登录` + 「退出登录」按钮；未登录时显示「未登录 / 部分功能受限」+「扫码登录」
- 头像目前只展示，点击无行为

## 方案

### 1. 触发与关闭

- 点击**整块用户卡**（头像 + 昵称区域，不含「退出登录」按钮）切换菜单；
- 点击菜单外部（`pointerdown` 冒泡到 document）、按 `Esc`、或选中菜单项后自动关闭；
- 菜单打开时用户卡加 `active` 浅底，箭头/高亮提示。

### 2. 菜单内容（自上而下）

| 项 | 图标 | 路由 |
| --- | --- | --- |
| 本地 | film | `/local` |
| UP 管理 | users | `/ups` |
| 收藏 | star | `/fav` |
| 设置 | settings | `/settings` |
| —— 分隔线 —— | | |
| 退出登录（危险色） | logout | 调 `logout()` |

- 未登录时：4 项照常（本地/设置不依赖登录），把「退出登录」换成 **扫码登录**（`ui.loginOpen = true`）；
- 当前所在页面项高亮（复用现有 `activePath` 判断）；
- 顺序**跟随侧栏自定义顺序**（`orderedNav` 过滤出这 4 个路径），用户拖拽排序后菜单同步变化。

### 3. 定位与视觉

- 绝对定位在用户卡上方 8px，宽度 `208px`，圆角 12px，背景 `var(--card)`，`box-shadow` + 1px `var(--line)`；箭头指向头像；
- 用 `fixed` + 根据用户卡 `getBoundingClientRect()` 计算（避免侧栏 `overflow` 裁切）；
- 层级高于侧栏（z-index 80），低于弹窗（100）；
- 移动端窄屏（< 640px）自动限制 `left ≥ 8px`、`right ≤ 视口 - 8px`，不超出屏幕。

### 4. 改动清单

| 文件 | 改动 |
| --- | --- |
| `app/src/App.vue` | `.side-account` 加点击切换；新增浮层模板（`v-if="userMenuOpen"`）；`onMounted` 加 document pointerdown/Esc 监听（`onUnmounted` 移除）；`userMenuItems` 计算属性 |
| `app/src/styles/global.css` | 新增 `.user-menu` / `.user-menu-item` / `.user-menu-sep` / `.side-account.active` 样式 |

无新接口、无新依赖、不影响已有页面。

### 5. 验收

1. 点击头像 → 菜单出现在用户卡上方，含 4 项 + 退出登录；
2. 点「本地/UP 管理/收藏/设置」→ 正确跳转且菜单收起；
3. 再次点击头像 / 点空白处 / 按 Esc → 收起；
4. 当前所在页面项高亮；
5. 浏览器 mock 与真机窄屏下菜单都不超出屏幕；
6. 未登录状态：菜单底部是「扫码登录」，点开登录弹窗。
