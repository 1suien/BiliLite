# 笔记条：点一下就记（本机 0.4.57）

## 改动

- 笔记条整条可点：点一下就地展开输入框并自动聚焦（已展开时不再收起，避免打字被打断）；
- 右侧「查看全部」「＋ 记笔记」按钮撤掉，换成 primary「保存」按钮（没内容时禁用）；
- 输入框展开后：左下显示 `@ 当前时间`，右下提示 `Ctrl+Enter 保存 · Esc 收起`；
- `Ctrl/Cmd+Enter` 或点「保存」→ 存到当前分P并自动收起；`Esc` 收起；
- 全量笔记仍在下方「笔记」tab（时间戳可点跳转、可删除）。

## 文件

- `app/src/views/VideoView.vue`：`openNoteBar()`（点条展开+聚焦，替代 `toggleNoteBar`）、模板 `.note-bar @click`、「保存」按钮、去掉 footer 按钮；
- `app/src/styles/global.css`：`.note-bar { cursor: pointer }`、`.nb-tip`。
