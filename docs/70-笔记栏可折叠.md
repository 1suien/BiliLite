# 笔记栏可折叠、视频可满宽（本机 0.4.51）

## 改动

- 播放页两列布局改为**可折叠**：
  - 默认收起：`grid-template-columns: minmax(0,1fr) 44px` → 视频占满内容宽度（1220 视口下约 910px，比 0.4.50 的 634px 大 40%）；
  - 展开：`1fr 320px`，视频平滑变窄（`transition: grid-template-columns 0.18s`）；
- 收起时右侧是 44px 竖条 `.note-strip`：`✎` + 竖排「笔记」+ 笔记条数小圆点（有条数才显示）；
- 展开时笔记栏头部右侧有「收起 ⌃」；
- 状态记 localStorage `study-bili-notes-open`，默认收起（`'1'` 表示展开）；
- 快捷键 `N` 开关笔记栏（输入框/文本域内不触发）；`Esc` 行为不变；
- 窄屏（≤1100px）保持单列：视频在上、笔记栏在下（原逻辑）。

## 改动文件

| 文件 | 改动 |
| --- | --- |
| `app/src/views/VideoView.vue` | `notesOpen` 状态 + `toggleNotes()`；`.watch` 加 `notes-closed`；收起竖条；笔记栏加「收起」按钮；`onKeydown` 加 `N` 快捷键 |
| `app/src/styles/global.css` | `.watch.notes-closed`、列宽过渡、`.note-strip`、`.ns-fold` 样式 |
