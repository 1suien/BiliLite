# 侧栏精简：隐藏入口、保留功能（计划，暂未写代码）

## 需求

截图圈出了侧栏里的 **本地**（主区）和 **UP 管理 / 收藏 / 设置**（「更多」区）：
**这些入口从界面上去掉，功能保留，统一从「点头像」的快捷菜单进入。**

## 现状（`app/src/App.vue`）

- 侧栏 = 主区导航（学习 / 习惯 / 课表 / 本地，按 `settings.navOrder` 可拖拽排序）+「更多」区（UP 管理 / 收藏 / 设置）+ 底部用户卡
- 0.4.40 已加：点用户卡弹出快捷菜单，含 本地 / UP 管理 / 收藏 / 设置 / 退出登录
- 路由全在 `app/src/router/index.ts`，与侧栏无关；`/fav` 等还有页面内跳转（如收藏夹页返回 `/fav`），不受影响

## 方案

### 1. 侧栏只保留 3 项

侧栏主区变成：**学习 / 习惯 / 课表**。

- `本地` 从主区移除；
- 「更多」分组（UP 管理 / 收藏 / 设置）整块移除，`.side-nav.side-more` 用 `v-if` 隐藏，避免留下空白分隔；
- 拖拽排序继续可用，只是只剩 3 项；`settings.navOrder` 里已存的隐藏项路径**保留不清**（以后想恢复入口时顺序还在）。

### 2. 功能保留 & 入口

- 4 个页面路由、组件、数据全部不动；
- 入口统一走 0.4.40 的头像快捷菜单（本地 / UP 管理 / 收藏 / 设置），当前页高亮、Esc/点外关闭等行为不变；
- 未登录也能打开菜单；「UP 管理 / 收藏」需要登录时会照旧提示，「本地 / 设置」不需要登录；
- 页面内已有的跳转（收藏夹页「返回收藏」等）照常工作。

### 3. 代码改动（很小）

| 文件 | 改动 |
| --- | --- |
| `app/src/App.vue` | 新增 `SIDEBAR_HIDDEN = ['/fav', '/ups', '/settings', '/local']`；`mainNav` 过滤掉隐藏项；`moreNav` 恒为空；模板里「更多」`nav` 加 `v-if="moreNav.length"`（同时去掉多余间距）；拖拽/高亮逻辑不变 |
| 无 | 路由、stores、页面组件、设置项都不改 |

### 4. 验收

1. 侧栏只剩 学习 / 习惯 / 课表，无「更多」分组、无空白块；
2. 点头像 → 菜单 4 项都能进；每页功能正常；
3. 侧栏高亮：在 /local、/fav、/settings、/ups 时侧栏无高亮（这些入口已不在侧栏），菜单里对应项高亮；
4. 拖拽 3 项排序后刷新仍生效；
5. 直接打开 `#/local`、`#/fav` 等 URL 仍能进入（保证旧书签/深链可用）。
