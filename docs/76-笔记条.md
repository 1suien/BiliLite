# 播放页常驻「笔记条」（本机 0.4.56）

## 为什么

笔记原本在 tabs 里，边看边记得往下滚、切 tab；现在视频下方常驻一条笔记条，紧贴清晰度工具栏上方，播放中随手能记。

## 行为

- 位置：视频 → **笔记条** → 清晰度/分P 工具栏 → 标题折叠行 → tabs；
- 收起态：`✎ 笔记 · N 条 · 最近一条（时间 · 前 40 字）` + 右侧「查看全部」「＋ 记笔记」；
- 点「记笔记」：条内展开输入框，自动带当前播放时间，`Ctrl/Cmd+Enter` 保存、`Esc`/「取消」收起，保存后自动收起并刷新「最近一条」；
- 点「查看全部」或最近一条：切到下方「笔记」tab（完整列表，时间戳可点跳转、可删除）；
- 只影响播放页，数据仍是原来的 `db.notes`（按视频 + 分P 存）。

## 改动文件

- `app/src/views/VideoView.vue`：`noteBarOpen`、`latestNoteText`、`toggleNoteBar()`；模板加 `.note-bar`（笔记条 + 展开的 `.nb-input`）；`saveNote()` 保存后收起输入框；
- `app/src/styles/global.css`：`.note-bar` 系列样式。

## 验证

- 浏览器 mock：`.note-bar` 存在、点「记笔记」展开 `.nb-ta`、保存/取消按钮正常；
- `npx vue-tsc --noEmit` 通过、`npm run build` 通过、`cap sync` + `gradlew assembleDebug` 通过。
