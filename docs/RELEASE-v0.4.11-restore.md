# BiliLite 0.4.11（本机构建）—— 还原工程 + 可安装 APK

这是 [BiliLite](https://github.com/1suien/BiliLite) 安卓端前端的**源码还原工程**在本机构建出的 debug APK。0.4.11 = 官方 0.4.4 的还原工程 + 前几版本机定制改动 + 本次「退出播放页后再次播放接着上次进度」。

## 这一版改了什么：退出后还能接着看

用户报告：「播放退出后再次播放无法继续上一次的进度」。查下来是两件事叠在一起：

1. **离开那一刻的位置没存住**：离开播放页时写学习进度用的是当前路由里的 bvid，而卸载时路由已经切走、bvid 变成空串，写库被当成脏数据静默丢弃。于是再次打开只能退回到「每 5 秒定时保存」的旧位置，看得短就干脆从 0 开始。
   → 改用本页实例打开时记下的稳定 bvid，退出前的真实位置现在会立刻落库。
2. **再次打开同一条视频时只显示占位**：0.4.8 起离开会自动缩成小窗，重开时页面只显示「视频正在小窗播放」不播放，看起来也像进度丢了。
   → 改成把小窗**收回本页，并从离开的位置继续播**。

细节与浏览器验收（9/9，另回归 6 套旧验收全过）见文档：`docs/18-退出后继续上次进度.md`。

> 注意：旧版本里已经被丢掉的那段进度找不回来，只会从旧版本最后一次成功保存的位置继续；从这一版起新产生的进度都会正确记住。

## 之前版本的定制改动（仍包含在本包内）

| 版本 | 改动 |
|---|---|
| 0.4.4 | 跟进上游 0.4.4：剧场模式「退出剧场」竖白条修复（原生侧与官方 0.4.4 APK 逐字节相同） |
| 0.4.5 | 笔记按「视频 + 分P」独立；输入框改成多行，回车换行、Ctrl+Enter 或点「保存」才存 |

| 0.4.7 | 笔记行去掉「▶ 跳转」、删除按钮挪到最右；小窗播放改成右下角 112×112 圆形气泡 |
| 0.4.8 | 播放中离开播放页时自动缩成圆形小窗并暂停，点小圆回播放页从暂停处继续播 |
| 0.4.9 | 删除「首页」：左侧导航、`/` 路由、`HomeView.vue` 全删，打开 App 直接进学习页 |
| 0.4.10 | 删掉自带的四个专注目标（不再自动生成，旧预设一次性清理，去掉「恢复默认」入口） |
| 0.4.11 | 退出播放页后再次播放接着上次进度；同一条视频重开时收回小窗并续播 |

## 安装

- 直接下载 `BiliLite-0.4.11-debug.apk` 装到安卓设备即可（允许「未知来源」）。
- 与官方版**包名相同、签名不同**：手机上装过官方 0.4.3/0.4.4 的会报 `INSTALL_FAILED_UPDATE_INCOMPATIBLE`，需先卸载官方版（卸载会清掉该应用本地数据——先在应用里导出一份备份）。
- 装的是本仓库 0.4.3–0.4.10 产物的可直接覆盖升级（同 debug 签名，versionCode `15 > 14 > 13 > … > 7`）。

## 已知限制

- 只在无头 Chromium（mock 桥 + 真实 webm 直链）里做了交互验收，**没在真机上验证**：安卓 WebView 上「按 Home 键切后台」走的可能不是卸载路径，仍按既有的「切换后台时定时保存」逻辑记进度。
- 既有规则不变：看不足 4 秒、或离结尾不足 12 秒时，下次仍从头开始。
