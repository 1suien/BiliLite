# 播放页标题区折叠（方案，未写代码）

## 现状

视频下面是一整块：

```
标题（可能两行）
正在播放：P28 L008 单词
UP 名 · BV 号 · 发布时间
[收藏] [关注] [加入学习清单] [学习面板] [小窗]
```

占将近 150px 高，播放时一直占着位置，把 tabs 和简介往下推。

## 目标

默认**折叠**成一行，点击展开完整信息。

## 方案

### 折叠态（默认）

一行，高度约 44px：

```
▶ 新概念英语 第三册 更新至47课 | 胶学 x 刘羽Leo …       展开 ⌄
```

- 左边一个小「▶/▾」箭头（或在行尾放一个「展开 ⌄」按钮，二选一）；
- 标题单行超长用省略号；
- 折叠时**不显示**「正在播放」、UP/BV/时间、收藏/关注/学习清单/学习面板这一整行；
- 节省出来的高度直接让 tabs 和简介上来。

### 展开态

点一下折叠条（或行尾「收起 ⌃」）→ 恢复现在的完整三块：

```
标题（1-2 行）
正在播放：P28 L008 单词
UP 名 · BV 号 · 发布时间
[收藏] [关注] [加入学习清单] [学习面板] [小窗]
```

### 细节

- 状态记在 localStorage（`study-bili-video-head-collapsed`），默认折叠；下次进播放页还是上次的展开/折叠状态；
- 折叠/展开不影响播放、不影响 tab 内容、不重新拉流；
- 切分P 时保持当前折叠状态（不自动展开）；
- 折叠条本身可以点击展开，箭头也要能点（点击区域大一点，方便触屏）。

## 改动文件

| 文件 | 改动 |
| --- | --- |
| `app/src/views/VideoView.vue` | 标题区外层加 `headCollapsed` 与折叠条；完整信息块 `v-show`；记住状态 |
| `app/src/styles/global.css` | 折叠条样式（单行省略、箭头、hover 高亮） |
