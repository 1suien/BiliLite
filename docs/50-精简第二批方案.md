## 连带影响与处理

- **搜索**：删掉顶栏搜索框后没有搜索入口了。搜索相关代码（`onSearch`、`/` 快捷键、搜索页路由 `/search`）保留，页面可直达；如果以后想留个入口，可以在首页加一个搜索 icon。默认这版就按「去掉搜索」处理。
- **今日 X h**：只是展示，删掉不影响统计（学习页「概览」里仍有今日番茄/专注时长）。
- **课表摘要**：`今日 N 项 / 学习 X 小时` 在删掉的进度卡与时间轴里仍能感知，删掉不丢功能。
- **已完成格**：完成度进度条（47%）仍按 完成数/总数 计算，只是不再显示数字格。
- **提醒卡**：只是说明文字，删掉不影响右下角提醒卡与系统通知。
- 布局：顶栏右侧变「剧场模式 + 返回」两个按钮，搜索框位置空出（左侧直接留白）；今日进度卡由 3 列变 2 列；课表标题行变单行。
