# 全量备份：实现记录（本机 0.4.61）

方案见 [docs/80-全量备份方案.md](80-全量备份方案.md)，这里记录落地情况。

## 新增文件

- `app/src/utils/backup.ts`
  - `BACKUP_TABLES`：21 张表（progress/daily/marks/notes/shelf/ups/upgroups/collect/collectfolders/checkins/upTime/books/bookmarks/highlights/focus/habits/habitLogs/slots/courses/subs/locals）
  - `BACKUP_LABELS`：每张表的中文名（概览/预览用）
  - `collectBackup({ version, settings, user })`：读全部表 + 设置 + localStorage（番茄 `study-bili-pomodoro`、课表状态 `study-bili-slot-status`），产出 `schema: 2` 的 JSON（`meta.counts` / `meta.bytes`）
  - `normalizePayload()`：兼容旧版（schema 1，顶层只有 progress/daily/notes/shelf）
  - `describeBackup()`：预览（每类条数、偏好项、总数）
  - `applyBackup(payload, 'merge' | 'replace')`：按表合并；`notes` 按 `bvid|cid|at|text` 去重；`daily` 取较大值；其余按 `updatedAt/at/readAt/createdAt` 较新者覆盖；无时间戳的旧记录保留本地
  - `applyBackupPrefs()`：设置返回 patch（调用方只补缺失项）、番茄/课表状态做对象合并
- `docs/80-全量备份方案.md`（方案）

## 改动文件

- `app/src/views/SettingsView.vue`
  - `DATA_VERSION = '0.4.61'`、`overview`（本地数据概览：各类条数 + 总数，进页面刷新）
  - `exportBackup()` 改调 `collectBackup`（全量）
  - `onImportFile()` 改为：解析 → `describeBackup` 预览弹窗（每类条数 + 偏好）→ 确认 → `applyBackup('merge')` + `applyBackupPrefs`（设置只补缺失）→ `learn.init(true)` → toast 汇总 → 有新增时自动刷新页面
  - 界面文案：`导出全部数据` / `导入全部数据…`，数据区顶部显示「本地数据：进度 N · 笔记 N …（共 N 条）」

## 安全

- 不写登录态（cookie/token）；`user` 只存 mid/uname 便于辨认
- `locals` 只存记录（文件名/时长/封面），换机后路径无效
