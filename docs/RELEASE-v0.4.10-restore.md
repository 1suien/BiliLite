# BiliLite 0.4.10（本机构建）—— 还原工程 + 可安装 APK

这是 [BiliLite](https://github.com/1suien/BiliLite) 安卓端前端的**源码还原工程**在本机构建出的 debug APK。0.4.10 = 官方 0.4.4 的还原工程 + 前几版本机定制改动 + 本次「删掉自带的专注目标」。

## 这一版改了什么：删掉「自带的专注目标」

学习页「专注目标」面板以前一打开就自带 阅读 / 刷题 / 看课 / 整理笔记 四个目标（代码里的默认值自动写进去的）。这一版把它们删掉：

- **不再自动创建**：全新安装时目标是空列表，显示「还没有目标，点右上角 ＋ 加一个」，要什么目标自己加。
- **旧数据一次性清理**：从 0.4.9 及更早版本升级上来，如果目标列表正好是那四个旧预设，第一次启动时清空，并写一个 `focusPresetsCleared` 标记——以后不会再清，自己加的目标不受影响。
- **删掉两处「恢复默认」**：专注目标面板右上角的刷新按钮、番茄钟里的「恢复默认」按钮（否则一按又变回那四个）。
- 专注记录不受影响：已删除目标的历史记录仍按原来的名字显示，也仍计入概览/记录列表。

细节与浏览器验收（11/11）见文档：`docs/17-删除自带专注目标.md`。

## 安装

- 直接下载 `BiliLite-0.4.10-debug.apk` 装到安卓设备即可（允许「未知来源」）。
- 与官方版**包名相同、签名不同**：手机上装过官方 0.4.3/0.4.4 的会报 `INSTALL_FAILED_UPDATE_INCOMPATIBLE`，需先卸载官方版（卸载会清掉该应用本地数据——先在应用里导出一份备份）。
- 装的是本仓库 0.4.3–0.4.9 产物的可直接覆盖升级（同 debug 签名，versionCode `14 > 13 > 12 > … > 7`）。
- 升级到 0.4.10 后第一次打开学习页，旧的四个默认目标会被清掉；这是预期行为。
