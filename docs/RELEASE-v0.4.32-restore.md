本机构建 **0.4.32**（debug 签名，可直接覆盖安装，数据保留）。

## 这一版做了什么

修「点进视频要转很久才出画面」（数据 0.2 秒就到、画面 16 秒才出）：

- 数据一到就起播：不再等 `play()` 完成才收尾，第一个视频分片 append 完就立刻起播；
- 起播看门狗：媒体已可播却还停着，自动补 `play()`（最多 12 次）；
- 卡住时不再傻转圈：6 秒还没出画面就提示「起播较慢：点一下画面开始播放」；
- 调试行加了「就绪 / 可播 / 播放 / append 次数耗时」，一眼看出卡在哪一段。

- 源码：分支 `restore/android-0.4.3`
- 设计说明：`docs/37-播放起播优化.md`
