## 3. 通知没有声音：改成系统默认提示音

### 为什么 0.4.13 会哑

0.4.13 用 `@capacitor/local-notifications` 建通道并指定自定义音效 `res/raw/bililite_reminder.wav`（三声短哔，22050 Hz 单声道 WAV）。看插件源码可以确认声音链路是：

- `NotificationChannelManager.createChannel(...)`：把 `sound` 的扩展名截掉，拼成 `android.resource://<pkg>/raw/<name>`，再 `setSound(uri, USAGE_NOTIFICATION)`；
- `LocalNotification.getSound(...)`：`AssetUtil.getResourceBaseName` → `getResourceID(context, name, "raw")` → `android.resource://<pkg>/<numericResId>`。

这条链路本身没错（资源在包里、通道也建了），但**自定义 WAV 在部分国产 ROM 上不会被通知播放器解码**，表现就是「通知弹了、没声音」。另外 Android 8+ 的**通道声音一旦创建就不可修改**，所以事后调参数也没用。

### 0.4.14 的做法

1. **新通道 id**：`bililite-reminders-v2`（旧通道 `bililite-reminders` 的设置不可改，只能换新 id）。
2. **自写一个极小的原生插件** `ReminderChannelPlugin`（`app/android/app/src/main/java/com/bililite/app/ReminderChannelPlugin.java`），在 Android 8+ 上建通道时把声音直接设成系统的默认通知音：

   ```java
   ch.setSound(Settings.System.DEFAULT_NOTIFICATION_URI,
       new AudioAttributes.Builder()
           .setUsage(AudioAttributes.USAGE_NOTIFICATION)
           .setContentType(AudioAttributes.CONTENT_TYPE_SONIFICATION)
           .build());
   ```

   这样「响不响、响什么」完全跟着平板自己的通知设置走，不再依赖 App 内嵌音频能不能被 ROM 解码。
3. **JS 侧优先用原生插件建通道**（`app/src/bridge/notify.ts` 的 `ensureNativeNotify()`）：先请求通知权限 → `ReminderChannel.ensureChannel()`；只有拿不到原生插件时才降级用 `local-notifications` 的 `createChannel`（不带自定义音效）。
4. 通知本身不再逐条传 `sound` 字段，声音由通道决定；同时删除 `res/raw/bililite_reminder.wav`。

### 设置页新增「提醒」区

| 按钮 | 作用 |
|---|---|
| **测试通知** | 立刻发一条本通道的通知（原生 `testNotification`，通知 id 47100），不用等提醒时间就能验证「弹不弹 / 响不响」 |
| **通知设置** | 直接跳到系统里本 App「到点提醒」通道的设置页（`Settings.ACTION_CHANNEL_NOTIFICATION_SETTINGS`），可以自己调重要性 / 声音 / 振动 |

浏览器预览里这两个按钮会提示「只在安卓 APK 里生效」（`nativeNotifySupported()` 判断 `Capacitor.isNativePlatform()`）。

## 6. 真机验证步骤

1. 覆盖安装 0.4.14（同 debug 签名，可直接升级；装过官方版需先卸载）。
2. 首次进入时允许通知权限；设置 → 提醒 → **测试通知**：应当**立刻弹一条通知并响一声**。
3. 若测试通知也不响 → 点**通知设置**，确认「到点提醒」通道：重要性不是「关闭」、声音不是「无」；再看系统「通知音量」是否静音/勿扰。
4. 设一个 1 分钟后的专注提醒（学习页 → 专注目标行 → 时钟 → 加一个时间），回桌面/锁屏等待：应弹系统通知 + 响一声；点通知应跳到学习页。

## 7. 限制 / 未验证

- **真机声音没能实测**（本机无设备）：代码路径与通道设置都是标准 API，但不同 ROM（尤其 MIUI/OriginOS 的自启动与通知管理）可能仍拦截；设置页两个按钮就是为这种排查留的。
- 通道声音不可改 → 以后要再换音效，需要把通道 id 升到 v3（`ReminderChannelPlugin.java` 与 `notify.ts` 两处同步改）。
- 课表不再有「提前 N 分钟」：到点即响；如果需要提前量，得再加回一个字段（这次按用户要求删掉了）。
- 旧课表记录里的地点/老师字段留在 IndexedDB 里未清理（只是不再显示），下次编辑保存时才被覆盖掉。
- 桌面小组件 / 通知内操作按钮（「去专注」按钮直接跳转）未做，点通知只能跳到对应页面。
