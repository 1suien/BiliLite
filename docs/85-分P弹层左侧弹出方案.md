# 分P 弹层改「按钮左侧弹出」方案（本机 0.4.64）

## 现状

0.4.63 弹层是「右对齐、向下、往左展开」，实际效果是盖在工具栏下方、右边缘贴按钮——看起来像从按钮下面伸出来，还会挡住笔记条/标题区。

## 目标

点「分P 155 ▾」时，列表**出现在按钮左边**（弹层右边缘贴按钮左边缘，垂直与按钮中线对齐），像下拉菜单往左翻。

## 交互与尺寸

- 位置：`right: calc(100% + 10px)`（贴着按钮左侧）、`top: 50%; transform: translateY(-50%)`（垂直居中按钮）；
- 宽 400px、高 `min(58vh, 460px)`，内部滚动（155 P 也够用）；
- 顶部：`≡ 分P列表 · 共 155P · 当前 P29 · 跳到当前`；
- 筛选框 + 分组（L008 / L009 …）+ 当前 P 高亮圆点，行高 32，点一行立刻切 P 并关弹层；
- 点外部 / Esc / 再点「分P」按钮关闭；
- 左侧空间不足时（窄屏 < 720px 或按钮太靠左）自动回退：改成底部抽屉（全宽、可下滑关闭）。

## 为什么不用“下方展开”

视频页工具栏下面紧跟着笔记条、标题折叠行、tabs——往下展开必定盖住它们，而且列表很长时会把页面顶下去。往左展开是唯一不遮内容主区的位置。

## 改动

- `app/src/views/VideoView.vue`：`.parts-wrap` 加 `position: relative`；弹层挂到 wrap 内；
- `app/src/styles/global.css`：`.parts-pop` 改 `right: calc(100% + 10px); top: 50%; transform: translateY(-50%); width: 400px; max-height: min(58vh,460px)`；
- 窄屏 `@media (max-width: 720px)` 保持底部抽屉；
- 点击外部关闭逻辑不变（`document` pointerdown 判断 wrap 内）。

## 验收

- 点分P：弹层左边缘落在「清晰度」区域右侧、右边缘贴住按钮左边，垂直居中；
- 155 P 可滚动、当前 P 高亮、点任意 P 能切并自动关闭；
- 点外部 / Esc 能关；
- 平板横屏（1610×1006 逻辑分辨率）下不超出内容区。

## 三个默认（不回就按这个）

1. 弹层贴按钮左侧、垂直居中（如上）；
2. 宽 400 / 高 58vh 上限，内部滚动；
3. 窄屏回退底部抽屉。

## 实现（0.4.64）

- `app/src/styles/global.css`：`.parts-pop` → `right: calc(100% + 10px); top: 50%; transform: translateY(-50%); width: 400px; max-height: min(58vh,460px)`；窄屏 `@media (max-width:720px)` 仍为底部抽屉（`transform:none`）。
