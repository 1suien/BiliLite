# 视频评论区（只读）（本机 0.4.36）

## 做了什么

播放页「简介 / 笔记 / 相关推荐」后面新增 **「评论（N）」** tab：

- **懒加载**：点进评论 tab 才发请求，不影响起播；
- **两档排序**：热门（默认，与 B 站一致）/ 最新；
- **分页**：每页 20 条，底部「加载更多评论」；
- **楼中楼**：每条先显示前 3 条回复，点「展开回复」每次多取 10 条；
- **UP 主标**：UP 自己的评论带 `UP` 角标；
- 头像、昵称、相对时间（刚刚/5 分钟前/3 天前…）、点赞数、IP 归属地；
- 换分P/换视频/重新拉流都自动清空重载；
- 加载失败给「重试」按钮。

**只做「看」**：发评论、回复、点赞都不做（需要登录 + 风控重，下一版再评估）。

## 接口

| 用途 | 接口 | 说明 |
| --- | --- | --- |
| 评论列表 | `/x/v2/reply/wbi/main` | **必须 WBI 签名**；`mode=3` 热门、`mode=2` 最新；`oid=<aid>`、`type=1`、`ps=20` |
| 楼中楼 | `/x/v2/reply/reply` | `root=<主评论 rpid>`、`pn/ps`，未登录可用 |

实测备注：

- 旧接口 `/x/v2/reply` 未登录可用，但**只返回热门**（`sort=0` 返回空），拿不到「最新」；
- 新版 wbi 接口不签名会返回 `-403`，所以统一走 `bridge/wbi.ts` 的 `encWbi()`；签名失败会自动清缓存重签一次；
- 评论数取自 `cursor.all_count`。
