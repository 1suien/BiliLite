# 备份：改成「备份所有数据」方案（本机 0.4.6x）

## 现状（问题）

设置 → 数据里的备份只导 4 类：`progress`（观看进度）、`daily`（每日时长）、`notes`（笔记）、`shelf`（学习清单）。导入也只合并这 4 类。换机/重装后这些都会丢：

- 设置（主题、默认清晰度、播放/字幕/提醒开关）
- 专注目标、专注记录（`focus`）、今日/总专注时长
- 习惯 + 打卡记录（`habits` / `habitLogs`）
- 课表时段（`slots`）与当天完成状态（localStorage）
- 本地视频记录（`locals`）、字幕（`subs`）
- 学习页目标/收藏夹缓存（`collect` / `collectfolders` / `ups` / `upgroups` / `checkins` / `upTime`）
- 书籍/书签/划线（`books` / `bookmarks` / `highlights`）
- 番茄设置与「上次任务」（localStorage `study-bili-pomodoro`）

## 目标

一份 JSON 覆盖**全部本地数据**；导出前看到「将备份多少类、多少条、多大」；导入前看到预览（每类新增/相同），可选「合并」或「覆盖」；旧版备份仍能导入。

## 新备份格式（schema 2）

```json
{
  "app": "study-bili",
  "schema": 2,
  "version": "0.4.60",
  "exportedAt": "2026-11-09T…",
  "device": "android",
  "user": { "mid": 123, "uname": "…" },
  "data": {
    "progress": [], "daily": [], "marks": [], "notes": [], "shelf": [],
    "ups": [], "upgroups": [], "collect": [], "collectfolders": [],
    "checkins": [], "upTime": [], "books": [], "bookmarks": [], "highlights": [],
    "focus": [], "subs": [], "locals": [], "habits": [], "habitLogs": [],
    "slots": [], "courses": []
  },
  "prefs": {
    "settings": { "theme": "…", "defaultQuality": 80, "…": "…" },
    "pomodoro": { "focusMin": 25, "breakMin": 5, "lastTask": "…" },
    "slotStatus": { "2026-11-09": { "3": "done" } }
  },
  "meta": { "counts": { "notes": 12, "…": 0 }, "bytes": 12345 }
}
```

- **不含登录态**（cookie / token）：安全，换机重新扫码即可；
- `locals` 只备份「记录」（文件名/时长/封面），路径换机无效，导入时标注「仅记录」；
- 兼容旧备份：顶层扁平结构（schema 1）继续可导入。

## 导入策略（默认合并）

| 表 | 合并规则 |
| --- | --- |
| progress / shelf / collect / locals / subs | 同主键取 `updatedAt`（没有就 `at`）更新 |
| daily | 同一天 `seconds` / `videos` 取较大值 |
| notes | `bvid+cid+at+text` 去重后补齐 |
| focus / habitLogs / checkins / marks / books 等 | 主键 upsert，不删除现有 |
| slots | 同时段（起止+星期）已存在则跳过，否则新增 |
| prefs.settings | 只补缺失项，不覆盖用户已改的设置（除非选「覆盖」） |

「覆盖恢复」：先确认（红色警告），清空所有表后写入备份内容，再重建设置/状态。

## 界面（设置 → 数据）

1. **数据概览卡**：`进度 12 · 笔记 8 · 专注 25 · 习惯 3 · 课表 6 …` 总计 `约 18 KB`；
2. 按钮：`导出全部数据` / `导入全部数据`；
3. 导出：生成 JSON → 系统「保存到」面板（安卓），完成后 toast 显示路径与大小；
4. 导入：选文件 → 预览弹窗（`进度 +3 / 相同 9`、`专注 +25`、`设置 补 4 项`）→ 选「合并」或「覆盖恢复」→ 执行 → 汇总 toast；
5. 大于 10 MB 时提示「文件较大，导入会慢一些」。

## 改动文件

- 新增 `app/src/utils/backup.ts`：`collectBackup()`（读全部表 + prefs/localStorage）、`applyBackup(payload, mode)`（合并/覆盖 + 每类计数）、`describeBackup()`（预览用）；
- `app/src/views/SettingsView.vue`：数据区改为「数据概览 + 导出全部 / 导入全部 + 预览弹窗」；
- `app/src/bridge/*`：不需要改（继续用 `bili.backup.write` 保存 JSON）；
- 文档 `docs/80-全量备份方案.md`（本文）+ 实现后 `docs/81-全量备份实现.md`。

## 验收

- 导出：JSON 里 20 张表 + prefs 都有，条数与页面概览一致；
- 导入（合并）：重复导入一份 → 各类「新增 0」，数据不变；
- 导入（覆盖）：清空后恢复 → 设置、专注目标、课表、习惯、笔记数量与导出时一致；
- 旧版备份（只有 4 类）仍可导入；
- 大文件（>10MB）提示正常。

## 分期

- **P0**：全量导出 + 全量合并导入 + 预览弹窗（本次）
- P1：覆盖恢复模式 + 自动备份（保留最近 3 份）
- P2：可选密码加密备份

## 三个默认（不回就按这个）

1. **不含登录态**（cookie/token 不写进备份）；
2. `locals` 的本地路径**写入但标注「仅记录」**（导入时不校验文件是否存在）；
3. 导入默认**合并**，覆盖恢复需二次确认。
