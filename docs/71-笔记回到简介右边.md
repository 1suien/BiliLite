# 笔记回到「简介」右边 tab（本机 0.4.52）

按反馈调整：不要右侧竖条/侧栏，笔记改回视频下方的 tab，位置在「简介」右边。

## 改动

- 删除 0.4.50/0.4.51 的右侧笔记栏与收起竖条（`.note-side` / `.note-strip` / `notesOpen` / 快捷键 N）；
- `.watch` 回到单列，视频占满内容宽（1220 视口下约 972px）；
- tabs 恢复为：**简介 / 笔记（N） / 相关推荐 / 评论**（笔记紧跟简介）；
- 笔记面板：输入框（placeholder 带当前时间，Ctrl+Enter 保存）+ 笔记列表；每条的时间戳是**可点按钮**，点了视频跳到那一刻；右边 `trash` 删除；
- 切分P/切视频时笔记按原逻辑重载（分P 独立）。
